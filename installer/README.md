# Marco TV 安装助手

Pilipala · 免费开源 · GPL-3.0-only · 助手 **1.0.0**，内含电视桌面 **0.12.0**。

**如果花钱购买了本软件，请尽快向购买平台申请退款。**

没有 U 盘，先打开 [安装向导](https://marcotv.wlj9919.top/install/)，选择电视系统、手边设备和电视提供的安装入口。能用电视浏览器或厂商文件接收功能时，可以直接使用电视 APK。

## 下载哪个文件

| 文件 | 在哪里使用 | 用途 |
| --- | --- | --- |
| `MarcoTV-Installer-1.0.0-Windows.exe` | Windows 10 / 11 电脑 | 直接运行，连接电视后安装；不需要另装 Python、Java 或 ADB |
| `MarcoTV-Installer-1.0.0-Android.apk` | Android 8 及以上安卓手机 | 先装在手机上，再通过家庭网络安装电视桌面 |
| `MarcoTV-0.12.0.apk` | Android 6 及以上电视 / 盒子 | 桌面本体，给电视浏览器、文件接收、U 盘等方式使用 |

## 第一次安装

1. 在电视原厂设置的“关于 / 系统信息”核实完整型号和 Android 版本。不能只根据品牌判断；三星 Tizen、LG webOS、Roku、tvOS 无法安装本 APK。华为、荣耀、VIDAA 等需要先核实实际 APK 兼容性。
2. 把电视和电脑 / 手机连到同一个家庭网络。尽量不用访客 Wi-Fi；电视用网线、手机用 Wi-Fi 也可以，只要路由器没有隔离它们。
3. 按 [各品牌电视设置入口](../docs/各品牌电视设置入口.md) 找到开发者选项与普通“网络调试 / ADB 调试”。部分机型需要在关于页连续选择版本号才能显示开发者选项；小米旧版可能直接在“账户与安全”提供 ADB 开关。**仅打开 USB 调试不保证网络可连接。**
4. 在电视网络详情找到 IP，记下实际连接端口。常见是 5555，以本机为准。只有“无线调试配对码”的电视暂不支持此助手，请换用向导中的其他路线或 [电脑配对说明](../docs/安装说明.md#73带配对码的无线调试)。
5. 打开电脑助手，或把安卓助手装到手机上。手机询问安装来源权限时，只给实际下载助手的浏览器 / 文件管理器开放对应权限。若电视另有安装限制，也需要按本机提示开放。ADB 安装是否允许由电视系统决定。
6. 在助手填电视 IP 和端口，也可以点“查找电视”。扫描只检查当前最多两个 `/24` 私有网段的 5555 端口；找不到可以手动填写。候选设备不一定是电视，必须连接后核对型号。
7. 点“连接电视”，用遥控器在电视弹窗选择允许。仅在自己的设备上选择“始终允许”。回到助手核对显示的品牌和型号。
8. 点“安装”，再次确认目标电视。助手先校验内置 APK，再传送安装。看到“安装成功”后点“打开桌面”，在电视完成首次引导。

安装助手不卸载原厂桌面、不清空现有 Marco TV 配置、不自动设置默认桌面、不自动授权无障碍或高级系统权限。系统最近任务等功能仍按 [完整安装说明](../docs/安装说明.md) 单独配置。覆盖更新后，任务辅助服务仍需重新启动。

## 遇到问题

- **连接超时 / 拒绝连接**：核对同网、IP、实际端口、普通网络调试开关和电视授权弹窗。不要把无线配对端口填作普通连接端口。
- **没弹授权窗口**：电视可能已信任这台设备，也可能端口不通。以助手是否读到电视型号为准。
- **点断开后**：连接会关闭，当前传送可能中止；如果电视已经开始安装，断开不等于回滚。先看电视应用列表，再重连重试。扫描可能需要几秒结束。
- **签名冲突**：不会主动卸载原应用；先从电视导出备份，再核实原版本来源。
- **已有更高版本**：助手不会强制降级。1.0.0 内含固定的 0.12.0，不会在每次启动时下载新包；安装后可在桌面“维护与帮助 → 软件更新”更新。
- **空间不足 / 系统禁止安装**：释放电视空间、核对安装限制后重试；不能绕过品牌禁装。
- **Windows 或手机提示风险 / 旧版应用**：Windows 助手暂未配置商业代码签名，安卓助手 targetSdk 为 28，新系统可能提示旧版应用或限制安装。先核对官网来源与 SHA-256；不要关闭系统防护，必要时选择其他安装路线。
- **只有 iPhone / Mac**：目前无对应助手。优先用电视浏览器或厂商文件接收；若只有 ADB，可以借用 Windows 电脑或安卓手机。
- **电视没有任何安装入口**：网页不能远程绕过限制，需要 U 盘或厂商支持的安装方法。

## 隐私与撤销

向导选择只在浏览器处理。助手不上传 IP、型号、日志或已安装应用列表，不连接云端安装服务；打开帮助网页会产生正常的网站访问。

助手仅接受私有 IPv4 地址，使用标准 ADB 授权。Windows 密钥保存在当前用户的 Windows 加密密钥容器中；Android 密钥保存在助手的私有数据目录，应用备份关闭。分发文件不含开发者连接密钥。

安装完成可关闭助手、按需关闭电视网络调试。希望撤销长期信任时，可在电视开发者选项中使用“撤销 USB 调试授权”（通常会同时撤销其他已信任电脑），之后再次连接需重新确认。卸载手机助手会清除其私有密钥，但不会卸载电视上的 Marco TV。传送使用普通局域网 ADB，不提供 TLS 配对，请只在可信家庭网络使用。

## 构建与测试

在 Windows 准备 [项目构建环境](../docs/构建说明.md)。下载官方 0.12.0 APK 到 `dist/MarcoTV-0.12.0.apk`；构建脚本固定核对其 SHA-256，不接受其他包替代。

```powershell
python installer/build.py
python installer/tests/run.py
```

构建输出在 `dist/`；中间文件与测试密钥在忽略的 `build/installer/`，不进入源码包。C# 使用 Windows 内置 .NET Framework 编译器，Java 使用项目工具链。签名沿用项目构建说明中的配置；自行构建的 Android 助手应使用自己的签名密钥，不会改变内置电视 APK 的官方签名。

自有电视可选运行 `python installer/tests/run.py --tv <电视IP>`，只验证型号读取和测试文件传输。加 `--install` 才会覆盖安装内置电视 APK。首次需在电视确认测试密钥授权。测试不会修改默认桌面和权限。实测范围与未覆盖项目见 [验证记录](VALIDATION.md)。
