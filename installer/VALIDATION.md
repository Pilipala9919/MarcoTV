## 尚未覆盖

- 没有实体安卓手机的跨设备端到端验收；手机系统的安装提示、后台限制及不同厂商 ROM 仍需复测。
- 未逐台验证其他品牌电视、Android 8 / 新版手机和 Windows 10；当前 Windows 窗口实测环境为 Windows 11。
- 不支持 Android 无线调试的 TLS 配对码流程，不提供 iOS / macOS 助手。
- 查找功能仅检查有限的私有 `/24` 网络及 5555 端口；候选必须在连接后核对型号。
- 断开不保证撤回电视已执行的安装；签名冲突、空间不足和禁止安装有对应提示，但未人为破坏测试电视来触发所有错误。
- 连接和安装通过不代表 Home 接管、Wi-Fi 设置、系统最近任务等高级功能全部适配。

使用说明列出了现有边界。桌面主程序自身的验证见 [项目验证范围](../docs/验证范围.md)。公开记录不包含家庭 IP、授权密钥、序列号或用户应用列表。
