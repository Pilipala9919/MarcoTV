**把电视桌面做到 Apple TV 的质感，还免费。**

作者：**Pilipala** · 当前版本：**0.21.3** · 协议：[GPL-3.0-only](LICENSE)

Marco TV 是免费开源的 Android 电视桌面：横向卡片、连续焦点动画、4K 60fps 动态壁纸，顺滑得不像第三方桌面。Magic Desktop 24 项调整配 3D 实时预览，卡片长宽、圆角、封面都能单独定制；手机扫码传图、无线投屏、最近任务、本地备份一应俱全。Android 6.0 就能用，老电视还有 Lite 版。

> **本软件免费开源。如果你付费购买了本软件，请尽快向购买平台申请退款。**

## 0.21.3 更新要点

- **免调试默认桌面分流与事务化取消保护**：「一键启用 Marco TV」在系统未提供桌面选择页但开放辅助功能时直接进入「Home 兼容」确认（无需 ADB），仅提供无线配对码时网页向导与应用指引同步指向手动辅助功能或官方 Android Platform Tools 配对说明；系统选择器与辅助功能授权均改为持久化事务，取消（含进程回收重建后取消、已是默认桌面暂停后取消）完整保留原暂停状态、HOME 别名、独立「开机打开」开关及已有验收记录，且在原生默认桌面日常状态检查中保留用户手动关闭「开机打开」的选择。
- **准确区分默认桌面、按键返回、窗口回拉与开机到达**：验收页分别呈现系统实际 HOME 解析、90 秒 Home 测试来源（系统 HOME／兼容按键或广播／原桌面窗口回拉，双击打开最近任务不误判短按）、按启动轮次去重的开机恢复请求与窗口实际可见获焦到达；Android 6 缺 `boot_count` 时以可靠 `boot_id` 建立基线并关联真实开机恢复，缺乏可靠标识时提供明确标注的人工观察入口。
- **原桌面回拉目标跟踪与撤销快照分离**：用户切换原厂桌面或重新启用兼容时更新窗口与任务桥回拉目标，同时保留本轮首次保存的原始恢复快照；原桌面临时停用时保留快照并允许重试。
- **任务桥 MiTV4 `ps -A` 仅表头回退与状态细分**：电脑端 `scripts/start_task_bridge.py` 与电视端 `HomeShellSetup` 仅在表头 PID 列存在有效数字行时接受 `ps -A`，否则回退普通 `ps`；电脑端区分「已确认运行」「已观察到进程但稳定性尚未确认」「发现候选进程但身份无法核实」「确认未运行」「无法验证进程列表」，`--stop` 遇到混合已核实与身份不可读候选时仅停止前者并分别报告 PID。
- **同步发布 Marco TV Lite 0.3.1**：修复系统选择器点击「仅此次」被误判为「当前已生效」的问题，改为以系统实际默认 HOME 解析判定，独立区分临时打开、已设为默认、其他桌面与受限版普通启动。

## 兼容性

**老电视实验分支：[Marco TV Lite 0.3.1](lite/README.md)**。独立安装，目标最低 Android 4.0（修复系统选择器「仅此次」误报为默认桌面，延续 0.3.0 品牌紫调叠卡视觉、应用管理与系统卸载、收藏行、拿起并移动、单卡封面与长宽高自定义、3 款零体积主题壁纸、媒体音量、屏保休眠定时及分类搜索，另提供无 `HOME` 声明的受限兼容测试包）；已通过 25+ 项本地与运行时默认桌面校验、API 14 真编译与小米 Android 9 历史实机界面验证，Android 4.x/5.1 老电视真机仍待实测反馈。功能与更新渠道独立，不影响下述完整版要求。

**更多机型等待实测反馈，欢迎加入测试！** 请通过 [GitHub Issues](https://github.com/Pilipala9919/MarcoTV/issues) 提交型号、系统版本与具体使用情况。

最低 **Android 6.0 / API 23**，targetSdk 为 28。实际开发和验证设备为 **Xiaomi MiTV-ASTP0、Android 9**。能安装 APK 与 Home 接管、自动恢复全部可用是不同验收项。

其他 Android / Android TV / Google TV 设备可按说明试装，尚未逐台验证。较新系统可能限制 Wi-Fi 配置、后台启动、无障碍授权或网络 ADB。**不适用于三星 Tizen、LG webOS、Roku、Apple tvOS；其他系统需先确认是否兼容 Android APK。** 先按品牌入口表核对实际系统。

普通桌面试用可通过 U 盘安装，不需要先授权 ADB。自动恢复及自动维护 Home 兼容服务，需要电脑通过 ADB 完成一次 `WRITE_SECURE_SETTINGS` 授权。Marco TV 可尝试恢复调试开关，不能保证打开所有设备的网络调试端口。

## 快速开始

1. 在 Releases 免费下载 `MarcoTV-0.21.3.apk`（或最新版本）。
2. 按安装说明确认系统，通过安装向导选择助手、电视浏览器、文件接收、U 盘或 ADB 安装。
3. 从原桌面的应用列表打开 **Marco TV**，先验证遥控器和应用启动。
4. 打开首页 **Magic Desktop**，调整壁纸、时钟和卡片；系统功能仍在左上设置齿轮中。
5. 需要默认桌面与自动恢复时，再授权并配置「开机与默认桌面」。

第一次安装保留原厂桌面；恢复流程见安装说明。

## 从源码构建

Windows x64、Python 3.10+：

```powershell
python scripts/bootstrap.py
python scripts/build.py
```

输出位于 `dist/`。工具从官方分发站下载并校验摘要，私钥只留在本机。已有 Android SDK 的 Windows、Linux 或 macOS 也可构建，详见[构建说明](docs/构建说明.md)。自行构建的签名与作者发布包可能不同，不能直接覆盖。
