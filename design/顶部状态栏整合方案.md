# 顶部「设置 + Wi-Fi」图标整合方案

> 本文档是设计思路，不是实现。可点击示意图见 `顶部状态栏整合方案.html`（含现状与 A/B/C/D 四个方案）。
> 用户指定的风格参照：苹果折叠机 **iPhone Duo**（2026-10-23 上市）的状态栏——**圆形设计**，右上角时钟下方是一个**圆形状态钮**，里面是加粗的 Wi-Fi 信号弧（圆滚滚的粗线条），系统图标统一为圆润造型。

## 为什么想改

现在的顶部是两个分开的图标：

- 左上角齿轮 → 打开「设置」（所有设置入口）
- 右上角 Wi-Fi → 打开「网络与 Wi-Fi」（看状态、连网络）

目标是 iPhone Duo 那种"状态图标聚成一个圆形控件、一个入口管一堆事"的设计。

## 方案 D · iPhone Duo 圆形状态钮（用户指定的方向）

**长什么样**：右上角时钟**下方**放一个圆形按钮——半透明圆框、里面是 iPhone Duo 风格的加粗 Wi-Fi 信号弧，圆框右上角一颗绿色小点表示"网络在线"。

**怎么用**：遥控器焦点移到这个圆钮，按确定，弹出「控制中心」面板：

- 顶部：时间 + 实时网络状态（有线/无线、Wi-Fi 名、IP、信号格）
- 下面几行：网络与 Wi-Fi（进现有网络面板）、进入设置（进现有设置根目录）、关于本软件

**状态反馈**：断网时绿点变灰、信号弧消失，圆钮里改显示感叹号。

**保留不变**：左上角齿轮 + "MARCO TV by Pilipala" 文字（招牌不动）；菜单键直接进设置的旧习惯不动。

## 方案 A · 药丸按钮

右上角（时钟左边）一个圆角长条：绿点 + Wi-Fi + 齿轮，按确定弹同一个控制中心面板。功能与 D 相同，只是外形是长条而不是 iPhone Duo 的圆钮。

## 方案 B · 视觉上合并、功能不合并

药丸按钮左右分区：左半开网络、右半开设置，弹出来的还是原来两个框。最像 iPhone 控制中心的外观，但"整合"只停在皮相。

## 方案 C · 半屏大面板控制中心

半屏大圆角面板从底部滑上来，一排大圆块开关。最像 iPhone 控制中心，但改动最大、遥控器操作不友好、回退成本高。

## 推荐

**方案 D**。用户明确点名 iPhone Duo 风格；D 在视觉上是 Duo 的样子（圆形状态钮 + 粗信号弧 + 绿点），功能上做到了真正的三合一（状态 / Wi-Fi / 设置），改动量适中且回退容易。

## 如果选了 D，实施时要注意

1. 保留菜单键 → 设置根目录的原有路径（老习惯不变）
2. 控制中心面板里「网络与 Wi-Fi」复用现有 NetworkPanel；「进入设置」复用现有 SettingsNavigator 根目录
3. 圆钮按当前连接状态实时绘制：Wi-Fi 信号弧 + 绿点；有线网络时画网线/地球图标；断网画感叹号
4. 圆钮用现有自绘 Canvas 画（项目不依赖图片资源），焦点选中时按现有动画放大
5. 原左上角齿轮点击行为改为直接进设置根目录（不变），只是少了一个顶层图标要重排焦点
6. 验收：34 项旧用例全过 + 新增：聚焦圆钮 → 确定 → 面板出现；面板内上下选择；Home 键关闭面板；断网时圆钮变灰
7. 版本号建议 0.10.0（新功能），不跟 0.9.x 抢号
