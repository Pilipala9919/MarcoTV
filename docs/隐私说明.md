# Marco TV 隐私与权限说明

作者：Pilipala · 版本：0.12.0-rc.6（预览版，手机管理与卡片交互预览） · 2026-10-28

Marco TV 在电视本地运行。当前源码未集成广告、分析统计、账号登录、支付或云同步服务，不向作者上传应用数据。在线更新会连接 作者镜像 marcotv.wlj9919.top、GitHub Pages 和 GitHub 发布下载服务；用户自行打开其他应用时，适用对应服务的规则。

## 本地数据

应用在本机保存显示设置、卡片顺序 / 隐藏 / 收藏、自定义名称和封面、本地壁纸，以及启用恢复功能时需要的原桌面和服务设置、最近恢复状态。卸载或清除数据会删除这些应用数据；当前无配置云备份。Android 的应用自动备份已关闭。

## 权限用途

| 权限 / 能力 | 使用场景 | 说明 |
| --- | --- | --- |
| 读取已安装应用信息 | 展示应用卡片 | 本地读取名称、图标、横幅及启动入口 |
| 网络状态 / Wi-Fi 状态 | 显示网络信息、扫描和连接 | 本地展示，不向作者上传 |
| 网络权限 | 本机调试端口检查、更新及用户开启的手机管理 | 更新仅访问作者镜像、官方 GitHub / GitHub Pages 及其下载域名，不上传设备诊断或应用清单 |
| 请求安装软件 | 用户确认更新 Marco TV | 需要系统允许未知来源安装和最终安装确认；不用于静默安装其他软件 |
| 定位权限与系统定位开关 | Android 9 附近 Wi-Fi 扫描 | 不读取地理坐标；由系统要求 |
| 读取共享存储 | 导入封面 / 壁纸及浏览备份 ZIP | 仅在用户主动选图或恢复备份时使用 |
| 修改音频设置 | 调整媒体音量 | 由用户滑块控制 |
| 开机广播 / 前台服务 | 用户启用开机和恢复功能 | 管理功能有可见服务通知 |
| WRITE_SECURE_SETTINGS | 自动恢复 ADB、维护自己的兼容服务、屏保设置 | 可选，需要用户经电脑一次授权；不是 root |
| 可选通知使用权 | 系统媒体会话 | 不处理普通通知内容，仅用于正在播放卡片 |
| 请求卸载应用 | 用户点击卸载 | 需要电视系统最终确认 |
| 无障碍服务 | Home 按键与原桌面窗口检测 | 仅用户启用 Home 兼容时使用；不读取屏幕正文、密码或聊天内容 |

Wi-Fi 密码交由 Android 系统网络配置处理，Marco TV 不把密码另存为应用配置或上传。无障碍服务观察必要的窗口包名以判断桌面切换；无法因此承诺厂商组件或其他应用的数据行为。

## 关闭与撤销

在「开机与默认桌面」恢复原桌面，并另行关闭 ADB 自动恢复；不再需要调试时在电视系统中关闭 ADB 和撤销电脑授权。可在 Android 应用权限页撤销存储 / 定位权限，这会影响对应功能。

公开反馈前请遮盖设备和网络标识。安全问题见 [SECURITY.md](../SECURITY.md)。

## 0.10.0 本地记录与可选播放权限

- 排序保存从 Marco TV 成功启动的应用标识与时间、置顶集合和自定义顺序；不申请使用情况访问权限，不监控其他入口的应用使用历史。
- 手动添加保存用户选择的包名和公开页面名称，用于生成可启动卡片。
- 「Marco TV 正在播放」使用可选通知监听授权取得系统媒体会话，只在桌面前台读取媒体标题、封面、来源和播放状态。通知监听服务不处理普通通知内容，不保存媒体历史、不上传数据；进入其他应用后注销会话观察。
- 封面使用播放应用提供的内存图片，不根据网络地址下载。
- 卸载仅打开系统确认界面，不能静默卸载其他应用；预装系统应用不会通过此入口强制移除。

可在「设备设置 → 正在播放卡片」关闭显示，并在电视系统撤销通知使用权；撤销 ADB 命令见安装说明。

## 0.11.1 备份与诊断

- 备份在本地创建，主动导出后由用户选择存储位置。备份含桌面配置、应用标识 / 最近启动时间和可选图片；不含 Wi-Fi 密码、系统授权凭据或其他应用的数据。不要把私人备份当诊断报告公开。
- 自动快照最多保留 3 份，手动快照由用户删除；恢复前另存一份原配置。系统权限、ADB 和默认桌面管理不从备份导入。
- 本地诊断默认启用，异常类型、Marco TV 自身代码位置、固定操作事件、运行中断及前台无响应线索写入内部目录。最多 7 天 / 5 MB，连续重复事件限频。报告额外包含品牌型号、版本与检查状态。
- 不写入异常消息原文、网络名称、IP、设备唯一标识、媒体名称 / 地址、通知正文、密码和完整应用列表。日志没有云端上传接口，不接第三方统计服务。
- 用户可关闭记录、清除内部日志，并预览后主动导出。关闭不会自动删除已有记录；清除内部日志也不会删除已导出的文件。
- 日志、内部备份和备用外部应用目录会随卸载清理；用户另存的文件需要自行管理。系统文件保存器若由用户选择云盘位置，其上传行为由该文件提供程序处理，Marco TV 本身不连接云备份服务。

## 可选系统任务辅助服务

由用户经电脑明确启动，以 Android shell 身份读取当前用户的系统任务编号、应用标识及系统允许提供的缩略图，用于返回原任务。数据仅在本机内存显示，不建立应用使用历史，也不写进诊断报告或备份。系统未提供缩略图时不另行录屏或抓取其他应用画面。

辅助服务通过受权限保护的本地 Binder 连接交给 Marco TV，并核对调用方 UID；不开放 TCP 监听、不保存 ADB 私钥。操作仅限状态、配置、读取任务、系统允许时切换或移除单个任务。启用唤醒恢复时读取电源交互状态和前台应用包名，仅在原厂桌面前台时启动 Marco TV；不记录屏幕正文。

辅助服务不会绕过厂商权限，不保证完整重启后保留。停止方法见安装说明。

## 在线更新（rc.2 起，rc.4 增加镜像）

默认开启版本检查，只在 Marco TV 运行于前台时调度，至少相隔 6 小时；可以关闭。可选自动下载，安装始终需要用户确认。更新方式与渠道保存在本机，不随桌面配置备份迁移。离开桌面后已开始的下载可继续，但不保证进程被系统结束后仍然完成；中断的下载可再次点击继续；主动取消会清除临时进度。

请求发送固定通用 User-Agent，不附加设备型号、序列号、MAC、应用清单、节目内容或诊断日志。作为网络服务提供方，镜像托管方（包括 Cloudflare）、GitHub 及其下载服务仍可收到来源 IP、请求时间等通常的网络连接信息。

缓存包含下载包、版本信息和校验摘要。安装前创建本地 before-update.zip 配置备份，含义与其他私有配置备份一致，不上传。未提供后台静默安装；校验失败、签名不同或版本不高于当前版本时不启动安装。

应用入口检查页仅显示用户选择的单个应用的包名、版本和查询结果，方便核对启动问题，不自动上传。

## 手机管理（rc.6 起）

在电视主动开启后才监听当前局域网接口；二维码连接码在 5 分钟后失效。每次连接需要电视确认，只允许本次配对的一个浏览器会话。15 分钟未操作或主动断开后关闭服务，完整退出 Marco TV 不保留连接。

配对手机可读取设备品牌型号、当前卡片名称和图片、已安装应用名称与公开入口、外观配置、剩余空间，以及用户主动预览的诊断报告和下载的备份。手机选择的壁纸或备份上传到这台电视，不上传作者网站、GitHub 或第三方云端。临时文件在处理后删除；应用的壁纸和本地备份保留到用户更换、删除或卸载。

这是家庭局域网 HTTP 服务，配对校验不等于链路加密。仅在可信网络使用，不要进行公网端口映射或分享带连接码的二维码截图。服务使用随机连接码、电视确认、会话 Cookie、来源及请求校验；不提供任意命令执行、远程 ADB、静默安装或其他应用的屏幕捕获。

未保存外观只存在于内存，停止调整 30 秒、离开桌面或关闭连接会取消预览。手机下载的备份可能包含私人图片和应用信息，请自行保管；诊断报告应预览后再分享。
