# 桌面启用与开机恢复：核心交接

作者：Pilipala · 2026-10-31 · GPL-3.0-only

本阶段完成 Android 6.0+ 正常版的核心实现和可执行回归检查。现有对话框仅供验证流程；界面、面向小白的文案、手机／电脑助手页面留给下一阶段。本次没有发布正式版本，没有更新 GitHub Release 或镜像更新索引，也没有修改 Lite。

## 已实现的行为

1. 优先使用系统提供的默认桌面选择。Android 10+ 尝试 HOME Role；其余版本尝试默认桌面设置。应用读取实际选择，不把打开设置页面当成成功。
2. 系统入口不可用时提供 Home 兼容模式。已有系统设置授权的设备可启用自身服务；未授权设备打开系统辅助功能页面，由用户决定是否开启。保留其他应用的辅助服务。
3. 提供实验性的电视本机增强设置。只连接电视自身的标准网络调试端口，使用应用私有、不参与备份的密钥。必须通过电视系统的调试确认；仅执行固定的自身权限与 HOME 设置命令，随后读取实际状态。
4. 开机恢复、Home 返回、系统默认桌面分别记录。普通打开应用不算 Home 测试；未观察到新启动周期不能确认重启成功。检测不到启动计数时保留“待验证”。
5. 用户暂停恢复、默认桌面发生变化或辅助服务在外部被关闭时，停止 Home 接管与开机兼容恢复，等待重新确认。不猜测外部变化究竟来自用户还是厂商系统。
6. ADB 恢复与桌面启用独立。本机授权不会自动开启持续 ADB 恢复；暂停桌面恢复不会改变已有 ADB 选择。
7. 本机授权可取消，连接关闭后不会继续后续命令；已有命令可能已生效，因此取消不等于撤销系统修改。总等待设置了 90 秒上限，单次授权读取另有超时。

## 实现接口

| 文件 | 责任 |
| --- | --- |
| `HomeSetup.java` | 读取能力与状态、显式开始、兼容授权返回、暂停、Home／重启证据 |
| `HomeSetupPolicy.java` | 独立于 Android 的路线和恢复判断，供 UI 使用 |
| `DefaultHomePanel.java` | 当前临时操作入口；保留既有页面 ID 和返回行为 |
| `LocalHomeAuthorizer.java` | 固定授权流程、取消、结果回读 |
| `LocalAdbWire.java` | 仅本机连接、ADB 密钥和传输；不提供任意命令 UI 或远程接口 |
| `BootReceiver` / `SystemIntegration` | 开机与辅助服务恢复；暂停和解锁状态检查 |

`HomeSetup.route()` 供下一阶段主操作按钮选择使用；当前入口保留显式的标准设置、兼容和实验选项。下一阶段应把这些路线收敛成主按钮及必要的后备入口，不要求普通用户理解 ADB。

状态保存在本机的 `system_integration` 偏好中，不进入用户配置备份。主要字段：

- `setup_requested` / `setup_paused` / `setup_pause_reason`：是否明确开始、是否暂停以及原因。
- `setup_accessibility_pending`：一次兼容授权是否仍待返回；返回或重新创建桌面后清除。
- `setup_native_seen`：明确开始后曾确认原生默认桌面；后续变化会暂停恢复。
- `setup_home_boot` / `setup_home_deadline` / `setup_home_seen`：90 秒 Home 测试窗口及返回记录。
- `setup_boot_armed` / `setup_boot_observed` / `setup_boot_confirmed`：设置时的启动计数、早期开机返回记录、用户确认。

暂停不撤销系统已经选择的默认桌面。需要退出 Marco TV 的用户应另行选择其他桌面；不要把“暂停自动恢复”写成“恢复原厂桌面”。

## 下一阶段：流程、界面与助手

1. **主界面**：一个“开始设置”主按钮，辅以“Home 返回”“开机恢复”两项独立状态。按 `route()` 给出下一步；保留“稍后”和返回。
2. **状态表达**：区分“系统默认桌面”“Home 兼容”“等待系统允许”“已配置但待实测”“已暂停”。不能统一写“永久生效”。
3. **系统返回**：取消授权仍回到原设置页面，聚焦回到原按钮；Home 退出后迟到回调不得重开菜单。
4. **助手**：更新现有手机／电脑助手说明与版本，继续使用固定命令与授权结果回读。实验本机授权不作为必须步骤。
5. **帮助**：精简“必须电脑输入指令”的旧文案，按设备能力分流。拒绝或取消授权后提供能执行的后备操作。
6. **常规测试**：开启电视并保持 Marco TV 前台，重跑新增 23 项核心检查；完成实体短按／双击／长按 Home、退出设置与返回焦点、屏幕关开，以及一次实际重启。完成系统授权后再检查本机增强路径。

建议切换到 **6.1 Sol High** 完成这一阶段。若遇到权限边界、厂商开机限制、Home 接管回归，交回 Astra 做核心判断。不得以界面完成代替这些待测项目。

## 发布前必须满足

- 最终 APK 的完整关键回归通过，验证记录与 APK 哈希对应。
- 本机增强设置保持实验标识，直到有现场授权与结果回读证据；非标准调试端口和配对码路线暂不支持。
- 真实重启和实体按键未测时必须明确说明，不承诺所有电视自动恢复。
- 不上传设备 IP、密钥、私人应用列表或播放内容；不把测试记录中的私有信息放进产品页。
- 正式版本号、发布说明、安装助手、GitHub 与镜像站在发布阶段统一更新。
