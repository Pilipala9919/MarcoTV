# Marco TV 详细安装说明

作者：**Pilipala** · 适用版本：**0.12.0-rc.4（预览版，更新与入口兼容预览）** · 核对日期：2026-10-24

> **本软件免费开源。如果你付费购买了本软件，请尽快向购买平台申请退款。**

[项目首页](../README.md) · [使用说明](使用说明.md) · [各品牌设置入口](各品牌电视设置入口.md) · [常见问题](常见问题.md)

完整流程：**核实品牌、型号与系统 → 确定安装方式 → 按需开开发者模式 → 允许安装来源 → 按需开 ADB → 安装 → 首次打开 → 可选授权 → 配置 Home / 开机 → 分项验收**。

> 本页设置路径按 0.12.0-rc.4 预览版编写。下文下载与安装命令仍以当前稳定版 0.11.1 为例；试用预览版时替换为对应文件名。

## 1｜先核实电视品牌、完整型号与系统

先看电视背面铭牌或购机记录，记录品牌和完整型号；不要只记“小米 55 寸”“海信电视”。再进入原厂桌面「设置 → 关于 / 设备信息 / 系统信息」查看软件版本与 Android 版本。

填写这张安装记录，不必把序列号公开：

| 项目 | 需要记录的内容 |
| --- | --- |
| 品牌、完整型号 | 如 Xiaomi MiTV-ASTP0，而不是仅屏幕大小 |
| 地区 / 固件 | 国行、海外版、运营商版、酒店模式等 |
| 实际系统 | Android、Android TV、Google TV，还是 Tizen、webOS、VIDAA、HarmonyOS 等 |
| Android 版本 | 至少 6.0 / API 23；名称相似不等于底层相同 |
| 系统版本 / 编译号 | 用来核对菜单入口和问题反馈 |
| 网络 IP | 只在自己家中操作时使用，不公开 |
| 安装方式 | U 盘 / 厂商安装入口 / 网络 ADB / USB ADB |

**先判断系统，再按品牌找入口。** 三星 Tizen、LG webOS、Roku、Apple tvOS 不能直接安装本 Android APK。华为 / 荣耀智慧屏、海信不同地区的 VIDAA 等不能仅凭品牌判断兼容；没有确认 APK 兼容环境前不要继续。

目前实测是 Xiaomi MiTV-ASTP0、Android 9；其他机型应按下面步骤逐项验证。最低版本符合不代表 Home、后台恢复等管理功能一定开放。

## 2｜准备安装包和工具

在[官方 Releases](https://github.com/Pilipala9919/MarcoTV/releases/latest)免费获取：

- `MarcoTV-0.11.1.apk`：电视安装包。
- `MarcoTV-0.11.1.apk.sha256`：文件校验值。
- `MarcoTV-0.11.1-source-and-apk.zip`：源码、许可、构建脚本与说明书；不是直接给电视安装的文件。

核对下载的 APK：Windows 在 APK 所在文件夹打开 PowerShell，执行：

```powershell
Get-FileHash .\MarcoTV-0.11.1.apk -Algorithm SHA256
Get-Content .\MarcoTV-0.11.1.apk.sha256
```

两处长串摘要应相同，大小写不影响比较。macOS 可用 `shasum -a 256`，Linux 可用 `sha256sum`。不一致时重新从官方 Release 下载。

选择 U 盘安装时，只需要电视可识别的 U 盘和 APK。选择电脑 ADB 安装时，从 [Google 官方 SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools)下载对应操作系统压缩包并解压；无需完整 Android Studio。

Windows 在解压后的 `platform-tools` 文件夹打开 PowerShell：

```powershell
.\adb.exe version
```

能显示 Android Debug Bridge 版本即工具可用。下文 Windows 示例使用 `.\adb.exe`；macOS / Linux 改为 `./adb`。如果已配置 PATH，也可以直接用 `adb`。

## 3｜选择路线：普通桌面试用还是完整管理

| 目标 | 所需步骤 |
| --- | --- |
| 先看看桌面、卡片和时钟 | U 盘安装即可；不必为此打开 ADB |
| 用电脑推送 APK | 打开对应 ADB 入口，连接后安装 |
| ADB 自动恢复、自动维护 Home 兼容 | 在 ADB 可连接后，额外授予一次系统设置权限 |
| 系统允许选择默认桌面 | 安装后启用 HOME 候选，并在系统选择 Marco TV |

**允许安装未知来源、USB 调试、网络调试、系统设置授权是不同开关。** 开启其中一个不代表其他全部开启；安装成功也不代表自动恢复已经配置完成。

## 4｜按需打开开发者模式

如果只用 U 盘，且电视允许安装，一般可跳过。需要 ADB、但设置中还看不到调试选项时，再执行。

标准 Android TV / Google TV 的常见路径：

1. 打开原厂「设置」。
2. 进入「设备偏好设置 → 关于」，或「系统 → 关于」。
3. 找到 **版本号 / Build / Android TV 操作系统版本号**。
4. 连续按确定，通常约 7 次，直到出现“您已处于开发者模式”或类似提示。
5. 返回上一层，找到「开发者选项」。

按到“Android 版本”出现彩蛋不等于进入开发者选项；应核对具体字段。部分品牌使用「产品型号」或厂商自己的方式，入口见[品牌表](各品牌电视设置入口.md)。菜单与说明不符时按完整型号查厂商说明，不使用不明工程码或工厂模式密码。

已能看到 ADB 调试开关的固件，不需要为了走流程重复激活开发者模式。[标准 TV 开发者入口依据](https://developer.android.com/training/tv/get-started/create#run-on-a-physical-device)。

## 5｜允许安装未知来源应用

从 U 盘、文件管理器或浏览器打开 APK 时，系统可能提示禁止安装。

旧 Android 常见「设置 → 安全和限制 → 未知来源」总开关；较新系统常见「应用 → 特殊应用权限 → 安装未知应用」，需要给**实际打开 APK 的文件管理器 / 浏览器**授权，而不是给所有应用授权。

例如索尼 Android 9 官方路径是「设置 → 设备偏好设置 → 安全和限制 → 未知来源」，再允许对应安装来源。[索尼官方说明](https://www.sony.com/zh-cn/electronics/support/articles/00146629)。

操作后应返回文件管理器，重新打开 APK。若仍提示管理员禁止、儿童模式或酒店策略限制，先退出受限模式或联系设备管理者；不要更改 APK 扩展名或删除系统安装器。ADB 安装是否经过同一限制由固件决定。

装好后可关闭不再需要的安装来源权限，Marco TV 正常启动不依赖它。

## 6｜安装路线 A：U 盘

1. 电脑将 `MarcoTV-0.11.1.apk` 复制到 U 盘根目录。
2. U 盘插到电视普通存储 USB 口。
3. 用电视自带文件管理器 / 媒体管理器 / 本地安装入口打开 U 盘。
4. 选中 APK，按需完成第 5 步的来源授权，再选「安装」。
5. 出现安装完成后，从应用列表打开 **Marco TV**。

U 盘可见但找不到 APK，可能该媒体浏览器只显示图片或视频，需换厂商提供的应用安装入口。找不到并不等于 APK 损坏。品牌不提供本地安装时，可使用它明确支持的 ADB 路线。

先验证方向键、应用启动和设置界面；普通试用到这里即可。需要完整管理时，继续打开 ADB 并授权。

## 7｜安装路线 B：打开 ADB 并用电脑安装

### 7.1｜准备网络与 IP

电视和电脑连接同一家庭局域网。电视可有线、电脑可 Wi-Fi，关键是能够互相访问，不在隔离的访客网络。到电视「网络 → 当前连接详情」记录 IP，或在路由器设备列表按电视名称查询。

以下 `192.168.1.100` 仅为示例，请换成自己的电视地址。IP 不是设备序列号，重连网络后可能改变。

### 7.2｜传统“ADB / 网络调试”开关

按品牌表找到「ADB 调试 / 网络调试」，设为允许。部分电视的「USB 调试」只开启 USB 通道，不会监听网络；**不能从打开 USB 调试推断 `5555` 已开放**。

仅当电视明确提供传统网络 ADB，且端口确实为 5555 时：

```powershell
$tvEndpoint = "192.168.1.100:5555"
.\adb.exe connect $tvEndpoint
.\adb.exe devices -l
```

电视出现「允许 USB / 网络调试」RSA 指纹弹窗时，核对是自己的电脑发起，选「允许」；可勾选始终允许这台电脑。再次执行 `devices -l`，目标行应为 `device`。

- `unauthorized`：连接已到电视，但还没有确认授权。
- `offline`：连接存在但不可用，重新连接并检查电视调试状态。
- 拒绝连接 / 超时：核对 IP、端口、调试开关、网络隔离及防火墙；不表示应该关闭认证。

如果厂商根本没有开放网络 ADB，仅靠电脑反复 `connect` 不会创造端口。

### 7.3｜带配对码的“无线调试”

部分新电视提供 Android 的「无线调试」。Google 官方说明的标准 TV 支持范围从 Android 13 起；更早固件可能使用厂商网络 ADB，不能混为一谈。

在「开发者选项 → 无线调试」允许当前网络，打开「使用配对码配对设备」。记下**配对地址、配对端口和配对码**：

```powershell
.\adb.exe pair 192.168.1.100:37001
```

按提示输入电视当时显示的配对码。然后回到无线调试主页面，读取它显示的**连接端口**；连接端口可能与配对端口不同：

```powershell
$tvEndpoint = "192.168.1.100:42123"
.\adb.exe connect $tvEndpoint
.\adb.exe devices -l
```

示例端口不应原样照抄，重启后也可能变化。以电视当时显示和 `devices -l` 列出的目标为准。[Google 官方配对说明](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi)。

### 7.4｜仅支持 USB 调试的电视

先读该型号厂商手册，确认哪个接口真正支持调试、是否需要设备模式及合适数据线。电视普通 USB 存储口不一定可当电脑调试口，不要把普通电视与电脑的主机 USB 口用不明双公头线直接相连。

打开「开发者选项 → USB 调试」，按厂商说明连接并允许电脑。`devices -l` 显示的 USB 序列号用于 `-s`。已经建立 USB ADB 的某些 Android 设备可使用 `adb tcpip` 转网络，但它不是未连接前开启 ADB 的通用办法，也不在本指南中默认执行。

### 7.5｜核实连的是自己的电视

```powershell
.\adb.exe -s $tvEndpoint shell getprop ro.product.manufacturer
.\adb.exe -s $tvEndpoint shell getprop ro.product.model
.\adb.exe -s $tvEndpoint shell getprop ro.build.version.release
```

品牌 / 型号 / Android 版本应与第 1 步一致。USB 连接时先把 `$tvEndpoint` 换为 `devices -l` 中的序列号。

### 7.6｜安装并打开

把 APK 放进当前目录，或把下面文件名换成实际完整路径：

```powershell
.\adb.exe -s $tvEndpoint install -r .\MarcoTV-0.11.1.apk
.\adb.exe -s $tvEndpoint shell am start -n com.pilipala.tvhome/.MainActivity
```

看到 `Success` 后确认电视已打开 Marco TV。`-r` 保留同签名应用的数据；签名不一致时不能覆盖，详见常见问题。`INSTALL_FAILED_USER_RESTRICTED` 应回到电视核对来源授权和管理限制，不使用卸载原桌面来处理。

## 8｜完成一次系统设置授权（可选）

需要 ADB 自动恢复或自动维护 Home 兼容服务时，在 ADB 已确认 `device`、且 Marco TV 已安装后执行：

```powershell
.\adb.exe -s $tvEndpoint shell pm grant com.pilipala.tvhome android.permission.WRITE_SECURE_SETTINGS
```

该命令成功时通常不打印内容。然后打开 Marco TV → 设置 →「系统与启动」→「状态中心」，核对授权状态。

也可在源码目录使用辅助脚本：

```powershell
python scripts/setup_system.py --adb "C:\Android\platform-tools\adb.exe" --serial "192.168.1.100:5555"
```

权限不是 root；不会因此自动绕过厂商固件。若返回权限拒绝、未知包或不允许授权，应检查连接目标、APK 与厂商限制。不要改授其他应用的权限。卸载 / 重装或恢复出厂后通常要重新授权，同签名覆盖升级通常保留。

## 9｜设置默认桌面与 Home

在「系统与启动」：

1. 选择「设为默认桌面」→ 阅读提示 →「继续」，启用本应用 HOME 入口。
2. 如果系统弹出默认桌面选择，选择 **Marco TV** 并设为始终使用。
3. 如果系统隐藏选择页，在已启用入口后可尝试电脑命令：

```powershell
.\adb.exe -s $tvEndpoint shell cmd package set-home-activity --user 0 com.pilipala.tvhome/.HomeActivity
```

部分旧系统没有该子命令，部分厂商即使命令成功仍固定系统 HOME。**命令成功不是验收结果**：请打开另一款应用，用实体遥控器按 Home。

若仍回原桌面，可在 Marco TV 开启「Home 键兼容模式」。该模式通过本应用无障碍服务直接响应 Home，未收到按键时用原桌面窗口切换兜底；不读取屏幕正文。系统无障碍设置中应显示「Marco TV Home 键兼容」。受固件限制时仍可能短暂闪过原桌面。

保留原厂桌面。若已有其他桌面接管 / 辅助恢复工具，先在其自身设置中停用接管；Marco TV 只会暂停已识别的冲突服务，不会自动卸载第三方软件。

## 10｜打开 ADB 自动恢复和开机打开（可选）

在相同页面按需启用：

- **ADB 自动恢复**：已授权后，尝试恢复被系统关闭的 `adb_enabled`。不会关闭认证，也不能保证恢复厂商网络端口、动态配对端口或驱动。
- **开机打开 Marco TV**：收到开机广播后尝试启动。厂商自启动、电池管理和后台启动限制会影响结果；优先使用系统默认 HOME。
- **Home 键兼容模式**：设备有需要时启用。

若系统提供自启动 / 后台运行 / 电池优化例外，可给 Marco TV 开放。具体菜单见品牌表；未找到时不意味着所有机型都有同一开关。强行停止应用后，Android 可能停止其广播与服务，需要手动重新打开。

管理功能会使用前台服务通知。只在自己信任的局域网中使用 ADB，不把调试端口映射到公网；只允许自己的电脑。装完不需要调试时，可关闭自动恢复、系统 ADB 并撤销电脑授权。

## 11｜安装后的分项验收

| 项目 | 操作 | 通过标准 |
| --- | --- | --- |
| 基本桌面 | 左右选择、确定打开应用 | 无闪退，可返回 |
| 设置返回 | 打开三级页面，逐次按返回 | 每次一层，首页再按返回回桌面 |
| Home | 从其他应用按实体 Home，重复几次 | 回 Marco TV；记录是否短暂闪原桌面 |
| 预览 | 改一格圆角 / 时钟，再恢复 | 画面即时变化，参数保留 |
| 屏保 | 等到当前等待时间 | 时间变大、背景变暗，方向键唤醒 |
| 正常重启 | 使用系统重启，不是遥控器待机 | 启动目标桌面，所需服务正常 |
| ADB 恢复 | 重启后重新连接并看运行状态 | 开关与实际连接都正常，而非只看状态文字 |
| 冷启动 | 单独在合适时机断电后开机 | 单独记录，不用正常重启结果代替 |

不使用本说明中的命令批量停用、删除厂商应用。先完成普通启动、再逐项启用管理功能，有助于定位哪一项受系统限制。

## 12｜更新、撤销与卸载

更新使用官方同一签名新 APK 覆盖安装，保留本地数据。不要先卸载，也不要清除数据；可先从「备份与恢复」导出设置与图片，另存到电视之外。

撤销步骤：

1. Marco TV →「系统与启动」→「恢复原桌面」。
2. 关闭「ADB 自动恢复」。恢复原桌面不会自动替你关闭这一项。
3. 用实体 Home 确认原桌面可用，必要时在系统重新选择默认 HOME。
4. 系统应用管理中卸载 Marco TV；或在确认目标后执行 `adb -s 目标 uninstall com.pilipala.tvhome`。
5. 不再使用 ADB 时，到原系统关闭调试并撤销电脑授权。

「恢复原桌面」会关闭 Marco TV 的默认入口、开机和 Home 兼容，恢复此前暂停且仍安装的辅助服务；不会重新安装已经卸载的软件。卸载会删除本地卡片、收藏、排序和导入图片。

## 可选：授权正在播放卡片

先从 Marco TV「正在播放 → 通知使用权」打开通知使用权设置，允许「Marco TV 正在播放」。系统通常将该权限归入特殊应用权限或通知使用权；不同电视入口不同，不等同于普通通知开关。

已通过本文步骤连接 ADB，且愿意启用媒体会话读取时，可执行：

```powershell
.\adb.exe -s $tvEndpoint shell cmd notification allow_listener com.pilipala.tvhome/.PlaybackListenerService
```

返回 Marco TV 后等待刷新。撤销方式：

```powershell
.\adb.exe -s $tvEndpoint shell cmd notification disallow_listener com.pilipala.tvhome/.PlaybackListenerService
```

这是 Android 9 本机验证过的系统命令。其他系统可能不提供该命令、限制低内存设备监听服务或要求使用系统界面；返回错误时不要视为授权成功，也不必为了桌面基本功能开启它。应用只使用媒体会话，不处理普通通知文本。播放应用还必须向系统提供会话和标题，授权不能让不支持的应用自动支持。

## 0.11.1 安装后引导与迁移

首次全新打开会进入可跳过引导，覆盖升级不强制重走。设置首页可进入「设置状态与引导」，逐项确认开关、授权与服务状态；不要只凭开关开启判断 Home 或重启恢复已验证。

旧电视迁移：先导出「设置与图片」，复制到 U 盘 / 电脑，再在新电视安装 Marco TV 并导入。系统权限、默认桌面和调试授权在新电视重新配置。若没有系统保存页面，软件会显示备用导出路径；请复制到电视之外再卸载。

出现异常时先从「本地诊断」查看状态和报告，可预览后导出用于反馈。自动记录只在本地，不会自动联系作者或上传数据。

## 可选：真正的系统最近任务与唤醒恢复

此功能需要电脑通过已授权 ADB 启动 Marco TV 自带的任务辅助服务；仅安装 APK 或授予 `WRITE_SECURE_SETTINGS` 不足以取得完整任务列表。无需另装辅助应用、无需 root，不需要开放新的网络监听端口。

1. 先完成本文安装、ADB 连接与 Home 配置。下载对应版本的源码包，在电脑解压并安装 Python 3.10 或以上版本。
2. 在解压目录运行下列命令，把 `YOUR_DEVICE` 换成 `adb devices` 中的电视标识；ADB 不在 PATH 时将 `adb` 换成工具的完整路径。

```powershell
python scripts/start_task_bridge.py --adb adb --serial YOUR_DEVICE
```

3. 电视打开「桌面设置 → 最近任务 → 状态中心」。必须显示“任务服务已连接”，电脑显示进程启动本身不能证明连接成功。
4. 打开「双击 Home」，从其他应用按一次 Home 应立即回桌面，快速按两次进入最近任务。可调整双击间隔。
5. 需要待机恢复时开启「Home 键兼容模式」及「唤醒后恢复桌面」。辅助服务在唤醒后只检查原厂桌面是否位于前台，符合时再打开 Marco TV；其他应用在前台时保留当前应用。

**普通待机与真正重启不同。** 当前辅助服务只在本次开机期间运行，完整重启、断电或更新 APK 后需重新运行启动命令。ADB 自动恢复不等于该辅助服务自动恢复。当前仅 Android 9 小米实机验证；其他版本的系统接口、权限和厂商限制可能导致无法连接。

系统最近任务不是所有后台进程，也不代表任务中的应用仍在内存。当前测试电视不提供任务缩略图，因此显示不透明的应用 Logo 卡片。它未开放直接移除任务的接口，但可通过已授权的窗口栈接口清除独立任务：执行前核对仅包含目标任务、当前用户及标准全屏模式；共享窗口栈、画中画和系统桌面不执行此兼容操作。

停止辅助服务：

```powershell
python scripts/start_task_bridge.py --adb adb --serial YOUR_DEVICE --stop
```

卸载或撤销前先停止辅助服务，并关闭双击 Home 与唤醒恢复。停止后普通桌面、卡片和已配置的 Home 功能仍可使用。

## 在线更新首次接入

0.11.1 及更早版本没有在线更新入口，先从官方 Releases 手动覆盖安装带更新功能的版本，不要先卸载。此后在“维护与帮助 → 软件更新”检查。电视可能要求额外允许 Marco TV 安装未知应用；此权限与 ADB 无关，需用户在系统页面开启。更新仍需安装确认。

系统安装器不开放、GitHub 下载不可达或签名不一致时，页面提示原因，保留 U 盘／电脑安装路径。更新不会帮助不同签名 APK 绕过系统限制。每次 APK 更新后重新启动最近任务辅助服务，并核对 Home 与待机行为。
