    03 — 每天开机，更顺手

    按 Home，回到喜欢的桌面

    先让系统选择

    打开 Marco TV 的桌面设置入口，按提示在电视系统中选择 Marco TV。有些电视不提供这一选项。

    再检查 Home

    打开另一个应用，按一次 Home。回到 Marco TV 后，方便时再重启电视，检查开机效果。

    遇到限制怎么办

    尝试 Home 兼容，或查看系统授权说明。原生默认桌面、Home 返回与重启恢复需要分别检查。

    0.15.0 已提供新版「桌面启用」与本机操作指引。当前版本未看到该入口时，请先查看完整安装说明中的默认桌面设置方法。

    为什么不能保证所有电视一键完成？

    电视厂商可能固定 Home 行为、限制后台启动，或在重启时关闭辅助服务。Marco TV 会提供可用路线和检查结果；系统确认弹窗仍需要你使用遥控器允许。
