# Marco TV 验证范围

作者：Pilipala · 2026-10-24

## 实机范围

作者当前实际验证设备为 Xiaomi MiTV-ASTP0、Android 9、1920×1080。其他型号、地区、系统升级、商店分发和长期连续运行未完成覆盖验证。

## 0.8.0

本版增加署名、免费开源 / 退款说明、离线许可及公开文档，保留已有功能。本轮 13 项实机检查通过：作者与版本、免费开源及退款提示、仓库地址、离线 GPL / Apache 许可、许可返回关于、关于返回设置、首页返回桌面、分类操作栏、滑块预览、Home 退出预览、安装 APK 与交付摘要一致、测试区间无致命异常。公开摘要为 [release-validation.json](release-validation.json)。

签名 v1/v2/v3 与 APK 对齐检查通过，10 项动画轨迹检查通过。按公开文件清单单独复制源码后构建成功，两个安装包除签名文件外的全部 15 项 ZIP 内容逐项一致。独立构建使用独立开发私钥，不拿其签名包替代作者发布包。

本轮没有重新执行关闭 ADB 后恢复、正常重启或断电冷启动；普通成功构建不能代替这些实机测试。

## 历史功能验证

0.7.0 的 26 项本机检查包括分类操作栏、网络详情逐级返回、首页返回桌面、Home 跨层退出、实时圆角预览及恢复、父页焦点恢复、屏保预览 / 重播、排序后动作对应、进程重启后保留、恢复原设置顺序和异步页面退出。该结果对应历史 0.7.0 安装包，不当作所有后续版本自动重测。

0.6.0 曾对本机进行普通重启、调试开关恢复、自身无障碍恢复、闲置屏保和厂商屏保兼容检查。正常重启与断电冷启动是两项，历史正常重启不能证明冷启动或全型号永久生效。

实体遥控器与 ADB 注入按键路径不同。本机曾有实体 Home 正常返回的反馈，也曾有偶发原桌面闪现反馈；不能承诺所有情况均无闪屏。原厂桌面仍保留。

## 尚未覆盖

- 断电冷启动、多品牌 / 多固件和长期运行。
- HDMI 实际切源、各型号外部图片选择器。
