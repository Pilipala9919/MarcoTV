# Marco TV 验证范围

作者：Pilipala · 当前版本：0.10.0 · 2026-10-24

## 实机范围

作者实际验证设备为 Xiaomi MiTV-ASTP0、Android 9、1920×1080。其他型号、地区、固件、应用商店分发和长期连续运行未完成覆盖验证。当前结果对应安装包摘要，见 [release-validation.json](release-validation.json)。

## 0.10.0 本轮验证

本版增加 Wi-Fi 信号图标、手动应用入口、背景色延展、播放卡片、单独卡片设置和三种排序。

- 26 项针对性设备检查：旧版缓存 / 导航回归，加上默认最近打开、置顶优先、拼音排序、自定义保留、背景铺满、公开入口校验与保存、无声音测试媒体会话的标题 / 状态 / 暂停 / 释放。
- 13 项新增界面检查：以临时无桌面入口应用验证手动搜索、添加、启动、置顶、隐藏恢复和卸载前确认，以及 Wi-Fi 信号列表、播放卡片焦点和控制菜单；不卸载用户已有应用。
- Wi-Fi 只刷新列表，核对名称与信号图标；未切换网络。OK 影视的实际媒体会话已显示标题、封面、来源及暂停状态；没有为了验证强行继续播放用户内容。
- 通用菜单回归、动画检查与工具检查的数量及安装包摘要见 [release-validation.json](release-validation.json)。截图和包含家庭网络信息的日志仅留本地。
- 从公开文件清单复制源码，使用独立签名重新构建；15 项非签名 APK 内容逐项一致。签名校验、APK 对齐和源码包 CRC 另行检查。

正在播放使用系统授权的媒体会话；播放器不公开会话、退出时移除会话或固件不允许通知监听时，不显示。测试会话验证控制路径，不代表所有视频应用均支持控制。默认最近打开仅记录从 Marco TV 启动的应用，没有采集其他入口使用历史。

本轮不重新执行重启、断电、真正换网或 HDMI 切源，不据此声称新系统和多品牌全适配。

## 0.9.2 历史验证

- 桌面与菜单：作者版本、离线许可、分类操作栏、逐级返回、Home 跨层退出、滑块预览、排序持久化与恢复、安装包一致、测试期间无致命异常，共 34 项。
- 针对性设备测试：共 8 项。强制启用通常在低内存机上关闭的图片缓存，验证重复导入封面、应用图标及横幅失效、无关图片保留；用受控系统设置与权限返回事件，验证网络页恢复和 Home 后丢弃回调。临时测试 APK 和专用测试封面在结束后清理。
- 本地自动检查：10 项动画轨迹检查、5 项内存解析与汇总检查。公开文件检查覆盖版本、许可、文档链接、发布清单以及源文件中写死的本机绝对路径 / 私网地址。
- 发布构建清理已删除或重命名类的旧编译结果；签名 v1/v2/v3、APK 对齐与源码包 CRC 单独核对。按公开清单复制源码、使用独立签名重新构建，15 项非签名 ZIP 内容逐项一致。

设备针对性测试覆盖的是实际 Android API 与应用导航逻辑，不是 Android 10 以上系统 Wi-Fi 面板的实机兼容验收。完整菜单回归使用 ADB 注入按键，也不能替代所有实体遥控器路径。

本轮不将短时间内存采样解释为长期稳定或更流畅。工具保留每次样本和中位数、采样最大值、首尾值；没有在两版本之间严格控制场景的观测不用于声称性能提升。

0.9.2 该轮未重新断电冷启动、关闭 ADB、改换实际 Wi-Fi 网络或测试 HDMI 切源。以下历史结果与本版结果分开记录。

## 尚未覆盖的发布后验收

- 另一台 Android 10 以上 Android TV / Google TV 的完整安装、权限、Wi-Fi 返回、后台启动与默认桌面流程。
- 同一版本连续 24 小时以上运行、重复待机唤醒、多轮断电冷启动。
- HDMI 实际切源、其他型号图片选择器和实际换到另一需密码 Wi-Fi 网络。
- 厂商系统升级后仍保持 Home / ADB 恢复。

公开仓库不附家庭网络与设备原始日志。品牌入口表中的“官方”“通用”“待型号确认”是资料等级，不是适配通过等级。完整菜单回归脚本含本机专用环境，仍保留在本地；公共针对性测试脚本可按构建说明在其他设备运行。
