# Marco TV 验证范围

作者：Pilipala · 当前版本：0.11.0 · 2026-10-25

## 实机范围

作者实际验证设备为 Xiaomi MiTV-ASTP0、Android 9、1920×1080。其他型号、地区、固件、应用商店分发和长期连续运行未完成覆盖验证。检查记录按安装包摘要区分；此前候选包的通用菜单、待机和实体遥控器记录保留原摘要，不算作最终安装包重复实测，见 [release-validation.json](release-validation.json)。

## 0.11.0 本轮验证

本版加入本地备份 / 恢复、首次引导和状态检查、诊断记录与导出、应用直接移动、播放来源与隐藏、系统最近任务和待机恢复。当前完成数量、摘要和结果见 [release-validation.json](release-validation.json)。

- 73 项针对性设备检查：保留此前 26 项，增加隔离配置空间中的备份往返、图片、缺失应用提示、恢复前快照、系统状态隔离、非法路径 / 错误格式 / 类型 / 越界参数 / 缺失图片拦截、中断回退、日志脱敏和容量 / 过期清理，以及左侧添加入口、空应用行导航、首项参与排序、添加后定位、移动取消、Home 取消、媒体来源和临时隐藏。
- 任务桥接 4 项连接检查、13 项真实任务检查：同一测试应用创建两个系统任务，核对独立编号与精确切换。此固件不提供任务缩略图；新增从底部展开的起止画面、不透明背景 / Logo、上滑单独清除、遥控器上键清除检查。使用系统独立窗口栈兼容清除，核对同应用另一个任务仍保留，测试 APK 卸载后清理。
- 最近任务设置与双击 Home 路由另有 9 项界面检查；测试应用另执行 4 项屏幕上滑检查，确认注入滑动后系统任务和对应卡片都被清除，不清除用户的现有任务。
- 此前 0.11.0 候选包（摘要以 `2980f7a0` 开头）执行一次受控关屏 / 唤醒：辅助进程保留、恢复 Marco TV、Home 服务连接及方向 / 菜单 / 返回键检查；注入 Home 单独等待 2 秒后核对前台。操作者另于 2026-10-25 使用实体遥控器确认该候选包 Home、双击 Home 和关屏唤醒“都正常”，未反馈原桌面闪现或方向键失灵。后续修改任务卡片和清除操作，这份反馈不改记到最终包，也不等于长期或所有型号无闪屏保证。不是断电冷启动。
- 备份自动测试使用隔离文件与配置目录，不替换作者实际桌面。真实界面验证快照、导出与同配置恢复，导出 ZIP 在电脑读取校验。
- 菜单及新增界面使用 ADB 注入输入，不代表所有实体遥控器路径。受控媒体测试不会暂停或继续作者的实际媒体内容。
- 设备测试工具重启目标应用后，曾观察到本机保留失效的 Home 无障碍连接；恢复原有服务连接后重测。公共测试脚本增加相同清理步骤，不将测试留下的失效连接计为 Home 检查通过。
- 新增功能界面共 27 项检查通过：其中 23 项在加入展开动画之前的候选包（摘要以 `e8787919` 开头）完成，最终包补验 4 项备份恢复操作；记录保留各自摘要。首次安装另用相同 Java 源码、独立应用标识验证 4 项引导行为，测试后卸载；这 4 项不算作正式安装包检查，也没有清空作者现有配置。
- 公开源码清单独立构建，15 项非签名安装包内容逐项一致；10 项动画、5 项工具检查另行验证。
- 没有云端服务或自动上传；不覆盖真实系统崩溃、所有 ANR、断电时最后一条日志写入、Android 13 文件选择器、外部 U 盘和云盘提供程序的全流程。

本轮没有重新执行完整系统重启、断电冷启动、真正换网、HDMI 切源或 24 小时稳定性测试。恢复中断测试是受控事务回退，不是电视断电实测。

## 0.10.0 历史验证

本版增加 Wi-Fi 信号图标、手动应用入口、背景色延展、播放卡片、单独卡片设置和三种排序。

- 26 项针对性设备检查：旧版缓存 / 导航回归，加上默认最近打开、置顶优先、拼音排序、自定义保留、背景铺满、公开入口校验与保存、无声音测试媒体会话的标题 / 状态 / 暂停 / 释放。
- 13 项新增界面检查：以临时无桌面入口应用验证手动搜索、添加、启动、置顶、隐藏恢复和卸载前确认，以及 Wi-Fi 信号列表、播放卡片焦点和控制菜单；不卸载用户已有应用。
- Wi-Fi 只刷新列表，核对名称与信号图标；未切换网络。OK 影视的实际媒体会话已显示标题、封面、来源及暂停状态；没有为了验证强行继续播放用户内容。
- 通用菜单回归、动画检查与工具检查的数量及安装包摘要见 [release-validation.json](release-validation.json)。截图和包含家庭网络信息的日志仅留本地。
- 从公开文件清单复制源码，使用独立签名重新构建；15 项非签名 APK 内容逐项一致。签名校验、APK 对齐和源码包 CRC 另行检查。

正在播放使用系统授权的媒体会话；播放器不公开会话、退出时移除会话或固件不允许通知监听时，不显示。测试会话验证控制路径，不代表所有视频应用均支持控制。默认最近打开仅记录从 Marco TV 启动的应用，没有采集其他入口使用历史。

本轮不重新执行重启、断电、真正换网或 HDMI 切源，不据此声称新系统和多品牌全适配。

## 0.9.2 历史验证

- 桌面与菜单：作者版本、离线许可、分类操作栏、逐级返回、Home 跨层退出、滑块预览、排序持久化与恢复、安装包一致、测试期间无致命异常，共 34 项。
- 针对性设备测试：共 8 项。强制启用通常在低内存机上关闭的图片缓存，验证重复导入封面、应用图标及横幅失效、无关图片保留；用受控系统设置与权限返回事件，验证网络页恢复和 Home 后丢弃回调。临时测试 APK 和专用测试封面在结束后清理。
- 本地自动检查：10 项动画轨迹检查、5 项内存解析与汇总检查。公开文件检查覆盖版本、许可、文档链接、发布清单以及源文件中写死的本机绝对路径 / 私网地址。
- 发布构建清理已删除或重命名类的旧编译结果；签名 v1/v2/v3、APK 对齐与源码包 CRC 单独核对。按公开清单复制源码、使用独立签名重新构建，15 项非签名 ZIP 内容逐项一致。

设备针对性测试覆盖的是实际 Android API 与应用导航逻辑，不是 Android 10 以上系统 Wi-Fi 面板的实机兼容验收。完整菜单回归使用 ADB 注入按键，也不能替代所有实体遥控器路径。

本轮不将短时间内存采样解释为长期稳定或更流畅。工具保留每次样本和中位数、采样最大值、首尾值；没有在两版本之间严格控制场景的观测不用于声称性能提升。

0.9.2 该轮未重新断电冷启动、关闭 ADB、改换实际 Wi-Fi 网络或测试 HDMI 切源。以下历史结果与本版结果分开记录。

## 尚未覆盖的发布后验收

- 另一台 Android 10 以上 Android TV / Google TV 的完整安装、权限、Wi-Fi 返回、后台启动与默认桌面流程。
- 同一版本连续 24 小时以上运行、重复待机唤醒、多轮断电冷启动。
- HDMI 实际切源、其他型号图片选择器和实际换到另一需密码 Wi-Fi 网络。
- 厂商系统升级后仍保持 Home / ADB 恢复。

公开仓库不附家庭网络与设备原始日志。品牌入口表中的“官方”“通用”“待型号确认”是资料等级，不是适配通过等级。完整菜单回归脚本含本机专用环境，仍保留在本地；公共针对性测试脚本可按构建说明在其他设备运行。
