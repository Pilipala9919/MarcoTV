# 各品牌电视设置入口与核对状态

作者：**Pilipala** · 核对：**2026-10-24** · 适用 Marco TV 0.12.0-rc.1（预览版，已完成小米 Android 9 自动回归）

> 本软件免费开源。如果你付费购买了本软件，请尽快向购买平台申请退款。

[安装总流程](安装说明.md) · [使用说明](使用说明.md)

本表讲的是软件调试 / 安装开关，不是电视机身电源按钮。**品牌、地区、型号、系统、固件版本必须一起核对。** 同品牌的 Android TV、国内定制系统、Roku、VIDAA 不能共用一套路径。

证据标记：**官方**表示厂商或系统官方资料中有该路径；**通用**表示采用标准 Android TV 操作，尚未对该品牌目标型号实测；**待型号确认**表示未找到可覆盖其固件的可靠入口，不提供猜测的工程码。

## 1｜已能给出明确路径的系统

| 品牌 / 系统 | 查看型号与开发者模式 | 未知来源安装开关 | ADB 开关及限制 | 证据与适用范围 |
| --- | --- | --- | --- | --- |
| 小米 / Redmi 国内部分旧版电视、盒子 | 设置 → 关于核对型号。若开发者入口隐藏，按本机关于页面提示激活；旧版官方另给出“应用商店 → 应用管理 → 系统应用 → 设置 → 开发者选项” | 主页 → 小米电视设置 → 账户与安全 → 允许安装未知来源应用；盒子可能多一层系统设置 | 同页“允许 ADB 调试”；旧官方 USB 路线还需开发者选项 → USB 调试。网络 ADB 不是所有固件默认开放 | **官方旧版路径** [S1]；本项目实测仅 Xiaomi MiTV-ASTP0 / Android 9，不泛化到全部澎湃 OS |
| 小米 / Redmi 海外 Android TV、Google TV | 使用下方标准 Android TV / Google TV 模板 | 使用对应安全 / 特殊应用权限模板 | 开发者选项中 USB 调试；有无线调试时按电视显示配对 | **通用** [S2][S3]，与国内系统分开 |
| 索尼 BRAVIA Android 9 | 设置 → 设备偏好设置 → 关于 → Build / 版本号连续选择；之后返回找开发者选项 | 设置 → 设备偏好设置 → 安全和限制 → 未知来源 → 允许实际安装来源 | 开发者选项 → 调试 → USB 调试；是否开放网络 ADB 需按型号确认 | 未知来源为**官方** [S4]，开发者为**通用** [S2]；不是本项目实机适配结论 |
| 索尼部分较新 Google TV | 设置 → 系统 → 关于核对版本；使用标准 Build 模板 | 快速设置 → 设置 → 隐私设置 → 安全和限制 → 未知来源 → 安装未知应用 | 系统 / 设备偏好设置中的开发者选项；动态无线调试只在提供该项时使用 | 来源开关为**官方指定帮助指南** [S5]；其他字段按实际系统核对 |
| TCL 海外 Android TV 4-Series | 设置 → 设备偏好设置 → 关于；开发者按标准 Build 模板 | 设置 → 设备偏好设置 → 安全和限制 → 未知来源 | 开发者选项 → USB 调试；网络端口须单独确认 | 安全菜单为**官方该系列手册** [S6]；开发者为**通用** [S2]，不适用于 TCL Roku / 国内全部机型 |
| TCL Google TV | 设置 → 系统 → 关于 → Android TV OS build，连续选择至开发者提示 | 在设置的应用 / 特殊应用权限中查“安装未知应用”，或按安装时跳转到来源页 | 系统 → 开发者选项，查 USB 调试 / 无线调试；没有网络项时不假定 5555 开放 | **通用 Google TV 模板** [S2][S3]，待具体型号验证 |
| 海信海外 Google TV（手册 ES-A232203 A 对应系列） | 设置 → 系统 → 关于，能查看 Android TV OS 版本和 build；激活开发者采用标准 Build 模板 | 设置 → 隐私中的 Security & Restrictions；具体“允许安装未知应用”来源以本机菜单为准 | 开发者为通用模板；网络 ADB 需看本机是否提供 | 关于 / 安全项为**官方该手册** [S7]，开发者**通用**，不是国内聚好看或 VIDAA 路径 |
| NVIDIA SHIELD Android TV | 设置 → 关于 → Build，按选择 7 次 | 按 Android TV 安全 / 安装来源模板核对 | 设置 → 开发者选项 → USB 调试。NVIDIA 官方说明特定型号 USB 接口需先切设备模式，不能随意接线 | USB 路线为**官方** [S8]；网络调试位置 / 端口待具体固件确认 |
| Amazon Fire TV（Fire OS 机型） | 设置 → My Fire TV / Device & Software → About，按设备名 7 次显露开发者选项 | Developer Options → Apps from Unknown Sources / Install unknown apps；按来源单独允许 | My Fire TV → Developer Options → ADB Debugging；IP 在 About → Network | **官方 Fire OS 路线** [S9]；本项目未实测 Home 接管，不能套用于非 Fire OS 设备 |

## 2｜国内定制系统：必须先补齐型号

以下列出查找方向，不把搜索关键词写成已经核实的固定入口。

| 品牌 | 先去哪查型号 / 系统 | 安装权限查找方向 | ADB / 开发者状态 | 下一步 |
| --- | --- | --- | --- | --- |
| 海信国内 / Vidda / 聚好看 | 原系统设置中的关于 / 系统信息，记录完整机型和软件号 | 应用管理、安全、安装来源；是否有本地安装入口由型号决定 | **待型号确认**；海外 Google TV 路径不能照搬 | 查该型号官方用户手册 / 客服，确认是否对用户开放调试 |
| 创维 / 酷开国内系统 | 设置或设备信息中查型号与酷开系统版本 | 查应用管理、安全、帮助与客服中的本地应用安装说明 | **待型号确认**；不提供网上流传的工程菜单密码 | 如应用安装入口开放可先 U 盘试用，ADB 需厂商确认 |
| TCL / 雷鸟国内定制系统 | 设置 / 系统信息中查机型、系统号 | 查应用管理、应用安装权限、系统安全 | **待型号确认**；不等于海外 Android TV 路径 | 以对应型号官方手册为准 |
| 长虹 / CHiQ | 设备系统信息或铭牌；在官方支持站按型号检索 | 查系统应用管理 / 厂商官方安装入口 | **待型号确认**，不使用服务菜单代码 | [长虹官方按型号查询](https://cn.changhong.com/fw/fwzccp/fwds/) |
| 海尔 / 卡萨帝 | 铭牌与关于 / 系统信息 | 查应用、安全与安装来源；不能用旧非智能电视说明推断 | **待型号确认** | [海尔官方支持](https://www.haier.com/support/)按完整型号查手册 |
| 运营商盒子 / 酒店电视 | 查看盒子自身型号和固件，不只看显示屏品牌 | 可能受管理策略限制 | **待设备所有者 / 管理员确认** | 明确允许安装与调试后再操作 |

这些品牌入口尚未完成逐型号实测。公开反馈时提供完整型号、固件、菜单路径和去掉个人信息的截图，有助于补全本表；不以“找不到开关”为由要求刷机或降级。

## 3｜不是直接安装本 APK 的系统

| 系统 / 品牌 | 判断 | 原因 / 资料 |
| --- | --- | --- |
| 三星 Tizen TV | 不适用本 APK | 三星开发文档使用 TV Web 应用 `.wgt`，不是 Android APK [S10] |
| LG webOS TV | 不适用本 APK | webOS 使用 `.ipk` 等自身应用工具链 [S11] |
| Roku / Apple tvOS | 不提供本项目安装路线 | 本项目未提供相应平台构建；连接 Android 盒子时安装目标是盒子 |
| 海信 VIDAA | 不因品牌相同就视为 Android | 先确认具体操作系统和 APK 兼容性，未确认不安装 |
| 华为 / 荣耀智慧屏 | 不提供统一的 Android ADB 安装承诺 | 新旧 HarmonyOS 与机型差异大；华为 HarmonyOS 5+ 官方应用安装渠道不能作为普通 Android APK 兼容证据 [S12] |

## 4｜标准 Android TV / Google TV 的开与关

| 开关 | 常见开启方法 | 关闭 / 撤销 |
| --- | --- | --- |
| 开发者选项 | 关于 → Build 连续选择至提示，返回后进入开发者选项 | 在该页顶部关闭；有些固件会隐藏该页 |
| USB 调试 | 开发者选项 → 调试 → USB 调试 | 关闭同一开关；可撤销 USB 调试授权 |
| 传统网络 ADB | 厂商提供的 ADB / 网络调试项 | 关闭该项；先关 Marco TV 的 ADB 自动恢复，否则它会按已启用设置尝试恢复 |
| 无线调试 | 开发者选项 → 无线调试，允许网络并配对 | 关闭无线调试，或在已配对设备中“忘记”电脑 |
| 安装未知应用 | 应用 → 特殊应用权限 → 安装未知应用，允许实际文件管理器 / 浏览器 | 取消该来源的允许，不影响已安装应用正常启动 |
| 自启动 / 后台运行 | 厂商应用管理中的对应选项，仅在该型号实际提供时配置 | 取消允许可能影响开机与恢复服务 |

USB 调试不等于网络 ADB，配对端口不等于连接端口，允许未知来源不等于授予系统设置权限。
