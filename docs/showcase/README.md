# Marco TV 产品展示

作者：**Pilipala** · 当前版本：**0.14.1** · 更新：2026-10-29

[在线展示](https://pilipala9919.github.io/MarcoTV/showcase/) · [产品图文版](../产品介绍与功能展示.md) · [项目首页](../../README.md)

Marco 互联专题、24 个模块、11 张 0.14.1 新素材、9 张 0.14.0 实机新素材，以及标明版本的历史截图与内置壁纸预览。按日常桌面、外观与操作、系统与媒体、维护与隐私分组，支持分类筛选、文本搜索、截图切换与大图查看。

## 离线查看

下载仓库源码并解压，用浏览器打开本目录的 `index.html`。保留 `style.css`、`app.js` 与 `assets/` 的相对位置即可。页面内容直接写在 HTML 中，不依赖在线接口；关闭 JavaScript 后仍可阅读全部模块和点击打开主图。外部下载、GitHub 文档和反馈链接需要联网。

## 素材与隐私

- 0.14.1 十一张实机截图使用临时示例卡片与内置海岸／极夜壁纸，原有素材仍标注其采集版本。

- 新版实机采集：Xiaomi MiTV-ASTP0，Android 9，Marco TV 0.14.0，2026-10-29。9 张新素材使用临时示例卡片、内置壁纸、示例网络和无效配对码。
- 历史实机采集：Xiaomi MiTV-ASTP0，Android 9，Marco TV 0.11.1，2026-10-26。
- 桌面卡片、收藏、HDMI 入口及无音频媒体会话使用临时示例，不代表预装应用、真实端口清单或内置影视。
- 应用库名称、最近任务名称及图标、网络名称、部分诊断时间与存储值经过不透明马赛克处理。色块独立生成，替换原像素后再编码，不能从公开文件恢复原内容。
- 原始截图、界面树、真实日志、备份、采集脚本与设备连接资料留在本地，不包含在仓库或网页中。WebP 不带 EXIF、XMP 或隐藏原图。
- 诊断页的服务状态属于采集当时的界面示例，不能代替实体遥控器、重启、待机和长期运行验证。拍摄后已恢复正常桌面并移除临时采集组件。
- 公开素材的文件名、脱敏区域数量和 SHA-256 见 [asset-manifest.json](asset-manifest.json)。模块文字见 [modules.json](modules.json)。
