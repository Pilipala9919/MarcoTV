01日常桌面↗

桌面与遥控器

用横向卡片组织常用入口，让电视打开后先看到自己的桌面。

从这里进入从原桌面打开 Marco TV；配置完成后可用 Home 返回。

  • 左右选择卡片，上下切换分类或顶部入口，确定打开。
  • 左上角打开设置，右上角查看时间、日期并进入 Wi-Fi。
  • 长按确定编辑卡片；菜单键打开设置。

使用前了解卡片来自已安装应用；不附带视频会员、频道源或付费影视。图中四张卡片为演示占位。

02日常桌面↗

收藏与输入源

把经常使用的内容放进收藏，按电视提供的入口切换输入源。

从这里进入卡片长按 → 加入收藏；桌面上下切换分类。

  • 加入收藏后显示收藏行，原分类中的入口仍然保留。
  • 名称和封面在收藏与原分类共用，行内顺序分别保存。
  • 选中输入源后按确定，交给电视系统完成切换。

使用前了解输入源是否出现及能否切换由固件决定；图中的收藏、HDMI 入口为临时示例，不表示所有电视都提供相同端口。

03日常桌面↗

左侧分类操作栏

到达最左侧后展开操作栏，常用操作不用绕进多层菜单。

从这里进入当前行第一张卡片 → 松开左键 → 再按一次左键。

  • 选择添加应用、编辑当前卡片、卡片外观、时钟与屏保或桌面设置。
  • 按右键或返回收回操作栏，回到卡片。

使用前了解添加应用位于左侧菜单，不占用桌面的一张应用卡片。

04日常桌面↗

应用库与手动添加

补上未自动识别的入口，也能按名称或包名查找。

从这里进入左侧分类操作栏 → 添加应用。

  • 在常用列表中选择应用，添加后定位到新卡片。
  • 通过搜索名称或包名缩小范围。
  • 需要更多入口时打开高级列表，查看系统组件与其他可启动入口。

使用前了解高级入口可能不适合电视或需要厂商权限；添加入口不会安装应用。实机应用名称已用马赛克遮挡。

05日常桌面↗

单张卡片管理

常用应用置顶，少用入口隐藏，卸载前保留系统确认。

从这里进入长按卡片 → 单独卡片设置。

  • 置顶卡片始终优先排列。
  • 隐藏仅从桌面与收藏收起，可在设置中恢复单张或全部。
  • 选择卸载会进入系统确认；不在桌面里静默删除应用。

使用前了解系统应用可能无法卸载；隐藏不等于卸载，也不会清除应用数据。

06日常桌面↗

名称、封面与收藏

让每张卡片适合自己的使用习惯。

从这里进入长按卡片 → 重命名 / 更换封面 / 加入收藏。

  • 重命名只改变桌面显示名称，最多 32 个字符。
  • 使用原始图标或横幅、本地图片，或四种纯色封面。
  • 恢复默认外观可清除该卡片的自定义名称与封面。

使用前了解本地封面居中裁剪为 16:9 并复制到应用；不支持视频封面或手动调整裁切位置。部分导入流程使用系统文件选择器。

07日常桌面↗

排序与拿起移动

默认把最近从桌面打开的应用放在前面，也支持手动编排。

从这里进入单独卡片设置 → TV 应用排序方式；长按 → 拿起并移动卡片。

  • 可选上次打开、首字母、纯自定义三种排序。
  • 拿起后左右移动，确定保存，返回或 Home 取消未确认移动。
  • 中文按拼音参与首字母排序，改名后的名称也参与比较。

使用前了解所有模式都优先显示置顶卡片；普通组不能越过置顶组。上次打开指从 Marco TV 启动的记录，不是全系统使用历史。

08外观与操作↗

卡片外观与实时预览

边调边看，让圆角、放大程度和文字亮度有直观参照。

从这里进入设置 → 卡片外观。

  • 调整圆角、选中放大幅度及未选中名称亮度。
  • 底部滑块显示当前数值，上方保留桌面预览。
  • 方向键每次微调一单位，长按加速，返回保留修改。

使用前了解数值按参数的最小单位连续调节，不是只有少数预设档位；滑块修改即时保存。

09外观与操作↗

四张壁纸与本地导入

雾蓝海岸、暖沙丘、极夜山脊与峡谷，也可以用自己的图片。

从这里进入设置 → 壁纸图库 / 更换本地壁纸。

  • 选择内置壁纸立即应用。
  • 导入本地图片，复制到应用内部后不依赖原文件。
  • 用壁纸亮度调整背景压暗程度，给卡片和文字留出对比度。

使用前了解图片按屏幕比例居中覆盖，边缘可能裁切；亮度控制不改变电视背光。卸载或清除数据会删除内部导入图片。

10外观与操作↗

时间与日期

粗体时钟放在右上角，日期紧随其下。

从这里进入设置 → 时钟与屏保 → 桌面时间大小。

  • 调整桌面时钟字号，实时查看与卡片的比例。
  • 日期保持独立固定字号，避免随时间一起过度放大。

使用前了解时间与时区来自电视系统；显示不准时应先校准系统时间。

11外观与操作↗

放大时钟屏保

闲置后放大并提亮时间，同时压暗壁纸。

从这里进入设置 → 时钟与屏保。

  • 设置等待时间、屏保时间大小、数字亮度、背景暗度和渐变时长。
  • 即时预览并重播过渡，方向键或确定先唤醒桌面。
  • 等待时间设为 0 时不自动进入。

使用前了解这是桌面时钟画面，不是关闭背光；厂商屏保与节能策略可能优先，需结合 Home 兼容和系统设置实测。

12外观与操作↗

设置导航与顺序调整

设置采用适合大屏的面板，返回路径清楚，常用项目可前移。

从这里进入左上齿轮或菜单键打开设置。

  • 子菜单按返回回上一级，设置首页再按返回回桌面。
  • Home 生效时可从任意设置层级直接回桌面。
  • 在支持排序的列表中长按确定，上下调整，确定放下。

使用前了解设置首页、卡片外观、时钟与屏保、设备设置、开机与默认桌面共五个列表可排序；系统授权、输入法与文件选择页面仍由系统提供。

13系统与媒体↗

网络与 Wi-Fi

热点名称搭配信号图标，减少不必要的信息堆叠。

从这里进入右上 Wi-Fi 图标，或设备设置 → 网络与 Wi-Fi。

  • 开启或关闭 Wi-Fi，刷新附近网络。
  • 选择网络进行连接，查看连接详情。
  • 每行保留名称和信号图标，连接时再处理安全类型。

使用前了解扫描和连接能力受 Android 版本、权限及厂商限制；展示中的网络名称全部遮挡，没有公开家庭 SSID 或地址。

14系统与媒体↗

音量与设备信息

常用设备设置放进统一界面，反馈问题时容易核对版本。

从这里进入设置 → 设备设置。

  • 使用音量滑块调整系统媒体音量。
  • 查看电视品牌型号、Android 版本、Marco TV 版本与作者。

使用前了解外接音响、HDMI 音量联动等行为由系统和设备决定；设备信息不等于对同品牌全部型号的适配承诺。

15系统与媒体↗

桌面正在播放卡片

回到桌面时，仍能看到播放器提供的标题、封面和状态。

从这里进入设备设置 → 正在播放卡片 → 允许通知使用权。

  • 播放器提供媒体会话时，左上出现播放卡片。
  • 桌面按上键进入卡片，确定打开控制菜单。
  • 没有封面时使用播放器图标。

使用前了解图中为无音频的临时演示会话；软件不提供片源。没有系统媒体会话时不伪造播放卡片，不读取普通通知内容。

16系统与媒体↗

播放控制与来源选择

有多个播放器时自己选择展示来源，也能临时收起卡片。

从这里进入播放卡片 → 确定；设备设置 → 正在播放卡片。

  • 返回播放应用，或在播放器支持时暂停、继续。
  • 自动模式优先正在播放，也可手动选择来源。
  • 暂时隐藏不会停止播放；可从设置恢复。

使用前了解控制能力取决于播放器。来源选择与临时隐藏只保留在本次进程；暂停会话观察满 30 分钟后收起，不记录观看历史。

17系统与媒体↗

系统最近任务

堆叠卡片返回上次页面，支持清除单个系统任务。

从这里进入先按安装说明启动电脑辅助服务，再开启双击 Home。

  • 单击 Home 回桌面，快速双击进入最近任务。
  • 左右选择，确定回到任务；遥控器上键或上滑清除所选任务。
  • 任务卡片从底部聚拢位置上移并展开，背景同步压暗。

使用前了解读取系统任务而非全部进程。清除只在系统与窗口栈支持时执行，不是清内存工具。优先系统缩略图，本次实测电视不提供缩略图，使用 Logo；名称和图标已遮挡。

18系统与媒体↗

最近任务外观与交互

把卡片大小、倾斜和动画调到适合屏幕与遥控器的程度。

从这里进入最近任务页按菜单键，或设置 → 最近任务与双击 Home。

  • 调整大小、间距、倾斜、圆角、背景暗度、动画时长、双击间隔和显示数量。
  • 滑块实时预览，试播切换可观察效果。
  • 动画时长可调 120–700 毫秒，默认 280 毫秒。

使用前了解完整重启、断电或更新 APK 后，辅助服务需从电脑重新启动。授权、启用状态和唤醒恢复开关不随备份迁移。

19维护与隐私↗

默认桌面、Home 与开机恢复

按电视能力选择接管方式，并把状态留在界面里。

从这里进入设置 → 开机与默认桌面。

  • 设为默认桌面，必要时开启 Home 兼容。
  • 选择开机打开、唤醒恢复以及 ADB 调试开关恢复。
  • 高级自动恢复按安装说明完成一次系统设置授权，再用实体遥控器验证。

使用前了解普通 APK 不能保证重启后打开所有品牌的网络 ADB 端口，也不能保证所有固件的 Home 接管。初装保留原厂桌面，先完成返回与撤销验证。

首次启动引导

先试用桌面，再按需要开启系统能力。

从这里进入首次全新安装；设置 → 设置状态与引导可重新查看。

统一状态检查

把默认桌面、权限、服务和播放状态集中在同一处。

从这里进入设置 → 设置状态与引导 → 状态检查。

  • 查看默认桌面、Home 服务、开机开关、ADB 恢复和播放授权。

本地备份与恢复

把外观和卡片配置带走，恢复前先看会改变什么。

从这里进入设置 → 备份与恢复。

  • 仅设置或设置与图片两种导出；最近 3 份启动后首次进入设置前的自动快照循环保留。
  • 选 ZIP 后查看来源版本、图片数和未安装应用数，再确认恢复。
  • 恢复前保存原配置，遇到失败尝试回退；重要备份应复制到 U 盘或电脑。

使用前了解本版没有云端同步。备份不含 APK、账号密码或系统权限，但包含私人应用配置和自选图片，不能直接公开。图中只展示恢复预览，未执行恢复。

本地诊断与异常线索

遇到异常时先检查、预览报告，再决定是否分享。

GET STARTED

先确认系统，再开始安装。

最低 Android 6.0。当前实测 Xiaomi MiTV-ASTP0 / Android 9。其他型号需逐项验证，三星 Tizen、LG webOS、Apple tvOS 等不能直接安装此 APK。

  1. 核对品牌、型号与系统按品牌入口说明找到设备信息，确认支持 Android APK。
  2. 安装并先试用桌面普通试用可用 U 盘安装；按需允许未知来源。
  3. 按需配置进阶能力Home、开机恢复及最近任务按说明授权和实测，保留原厂桌面。
