# TCL 75T8G Max · 最近任务与 Home 排查

作者：Pilipala · Marco TV 0.13.2 · 2026-10-29

用户反馈的系统为 Android 11。反馈中“双击出现界面但服务未连接”和“长按 Home 不再出现原厂任务界面”是两条不同链路，不能混为系统没有后台任务。

0.13.0 将 Home 短按和长按区分：短按在松开时返回桌面，长按默认请求系统最近任务；可在「系统与启动 → Home 长按与原厂兼容」改为 Marco 最近任务、不执行操作，或完整放行原厂 Home 按键。原厂模式可能经过原桌面，双击行为受固件控制。

系统最近任务入口使用系统提供的操作，无法保证厂商实际显示。此 TCL 尚未完成新版实机验证。

1. 打开两个应用再双击 Home。若提示服务未连接，按确定打开恢复选项，不再只有一行不可操作的提示。
2. 电脑使用安装说明中的任务服务启动工具重新连接；完整重启、APK 更新或系统清理可能导致服务断开。刷新检查，确认能读到任务后再验证切换和移除。
3. 长按不能唤起原厂界面时，先试「保留原厂 Home 按键」。此模式保留原始按键链路，不能同时保证完全不经过原桌面。
4. 分别测试短按、双击、长按、关屏再唤醒；记录完整固件号与异常步骤。可通过 Marco 互联下载脱敏诊断。

用户已说明此前云视听小电视无法打开，是清理工具停用了应用；这不再作为已经确认的 Marco TV 启动兼容缺陷。请先在系统应用管理恢复启用，再比较原厂桌面和 Marco TV 的启动结果。
