## 1｜认识桌面

从原桌面的应用列表打开「Marco TV」。左上是设置齿轮及署名，右上是 Wi-Fi 入口、时间和日期。下方横向卡片显示应用、收藏和输入源；加入收藏后出现收藏行。时间与时区来自电视系统。

应用名称、图标和横幅来自电视已安装的应用。Marco TV 不预装视频会员、频道源或付费影视内容。系统能识别的输入源才会出现，实际切源还取决于固件。

| 分类操作栏 | 右或返回 | 收回操作栏 |

| 设置首页 | 返回 | 关闭菜单，回桌面 |
| 任意设置层级 | Home | 直接回桌面；需默认桌面或 Home 兼容生效 |

厂商可能接管 Home、菜单或语音键。首次安装应使用实体遥控器验证，电脑模拟按键只能辅助检查。

## 3｜分类操作栏

到当前行最左侧卡片，再单独按一次左键。操作栏从左侧展开，卡片平滑右移。

- **添加应用**：打开应用库，可搜索和手动添加未识别的应用。
- **编辑当前卡片**：移动、改名、封面、收藏和单独卡片设置。
- **卡片外观**：整体圆角、放大幅度与名称亮度。
- **时钟与屏保**：桌面时钟及闲置显示。
- **桌面设置**：进入设置首页。

右键或返回收回。按住左键到边界后，松开再按一次更容易准确打开。

## 4｜卡片编辑

在卡片上长按确定，或从分类操作栏选择「编辑当前卡片」。

### 移动卡片

「向左移动」「向右移动」立即保存顺序。应用行、收藏行、输入源行分别保存，移动不会越过该行边界，也不改变系统应用列表。

### 改名

「重命名」最多输入 32 个字符，只改 Marco TV 显示名，不改系统应用名。使用电视输入法，也可接键盘。

### 换封面

「更换封面」支持原始图标 / 横幅、本地图片，或午夜蓝、森林绿、暖琥珀、雾紫纯色封面。

把 PNG、JPG 或 WebP 放入电视共享存储的 `Download` 或 `Pictures`。优先调用系统图片选择器，缺少时使用内置文件浏览器；首次可能需允许存储权限。

图片居中裁剪为 16:9，缩小至 640×360 后存入应用，不修改原图。之后移走原文件仍可显示。当前不支持手动移动裁剪位置、视频封面、动态封面或图标包。单目录最多列出 300 项。

### 收藏、隐藏和恢复

「加入收藏」后出现收藏行，原分组保留应用；两处共用同一名称与封面。再次编辑可取消收藏。

「单独卡片设置 → 隐藏卡片」从桌面和收藏隐藏，不卸载。设置首页 →「恢复隐藏的卡片」，可恢复单张或全部。

「恢复默认外观」清除该卡片自定义名称与封面，不取消收藏或排序。「应用信息」显示版本与包名；输入源卡片则提供「打开输入源」。

## 5｜卡片外观与实时预览

设置首页 →「桌面与外观 → 桌面卡片样式」。

| 项目 | 范围 | 默认值 | 效果 |
| --- | --- | --- | --- |
| 卡片圆角 | 0–90 | 32 | 越大越圆 |
| 选中放大幅度 | 0–30% | 16% | 焦点卡片放大程度 |
| 未选中名称亮度 | 0–100% | 0% | 其他卡片名称的可见程度 |

滑块在底部，使用当前壁纸与真实卡片实时预览。卡片行上移，避开控件。每次改变即保存，左右微调、长按加速，返回回到外观页。

「恢复默认外观设置」恢复全局外观参数，不删除单张封面、收藏或改名。

## 6｜壁纸

设置首页 →「桌面与外观 → 壁纸 → 内置壁纸」，内置雾蓝海岸、暖沙丘、极夜山脊及峡谷。选择立即应用，按屏幕比例居中覆盖，边缘可能裁切。

「壁纸压暗程度」控制背景压暗程度：数值越大越暗，不调整电视背光。

自己的图片：设置首页 →「桌面与外观 → 壁纸 → 导入本地壁纸」。优先使用系统图片选择器，缺少时提供内置目录浏览。壁纸复制到应用内部；卸载或清除数据会删除导入图片和本地设置。

## 7｜时钟、日期与屏保

设置首页 →「桌面与外观 → 时钟与屏保」。屏保放大并提亮时间、压暗壁纸，不关闭背光。

| 项目 | 范围 / 选择 | 默认 | 说明 |
| --- | --- | --- | --- |
| Marco TV 屏保 | 开 / 关 | 开启 | 控制本桌面自动屏保 |
| 进入屏保等待 | 0–600 秒 | 30 秒 | 0 表示不自动进入 |
| 桌面时间大小 | 36–160 | 96 | 日期独立保持固定字号 |
| 屏保时间大小 | 100–280 | 176 | 实际至少不小于桌面时钟 |
| 屏保时间亮度 | 40–100% | 100% | 数字透明度，不是背光亮度 |
| 屏保背景压暗 | 0–100% | 72% | 至少不比桌面背景亮 |
| 渐变时长 | 1–30 秒 | 3 秒 | 放大时间与压暗壁纸的时长 |

调整桌面时间时显示桌面，调整屏保尺寸、亮度和背景时显示屏保。「渐变时长」提供「重播预览」。「立即预览屏保」也可反复观看过渡，返回后仍在时钟设置。

屏保下方向键或确定先唤醒桌面，避免误启动应用；电源键仍由系统处理。

应用注册标准 Android 屏保服务。部分小米固件使用厂商专用屏保，Home 兼容服务在已验证设备上可切回本应用的时钟画面；不代表其他品牌已适配。原系统屏保仍出现时，检查屏保、Home 兼容和系统节能设置，保留厂商组件。

## 8｜设置列表排序

设置首页和各主题下的固定设置列表支持排序，包括壁纸、桌面卡片、时钟、应用管理、最近任务及外观、播放、网络、系统、维护、备份、状态和诊断。升级会保留原有顺序：合并项按旧列表中首次出现的位置归组，新项目追加到末尾。

1. 选中目标条目，长按确定。
2. 出现 `↕` 和移动提示后，按上 / 下移动。
3. 按确定放下。

也可点击底部「调整顺序」，从该页最后选中的项目开始移动。即时保存，重启应用保留。返回先结束排序，再按返回才退出该页。附近 Wi-Fi 结果不参与自定义排序。

## 9｜网络、声音和设备信息

齿轮 →「网络与声音」，或直接打开右上 Wi-Fi。

- **网络与 Wi-Fi**：状态、连接详情、Wi-Fi 开关和附近网络。扫描可能需定位权限及系统定位开关，仅用于系统 Wi-Fi 扫描，不读取位置坐标。
- **媒体音量**：媒体音量滑块。
设备信息位于「维护与帮助 → 设备信息」，显示品牌、型号、Android API 和固件版本；作者与软件版本见「关于 Marco TV」。

应用内网络控制主要针对 Android 9，支持已保存、开放和 WPA/WPA2 个人网络。Android 10 及以上为兼容不同厂商，Wi-Fi 开关与连接交给系统设置：点击操作后的「打开 Wi-Fi 设置」。系统返回时回到网络菜单，按 Home 则回到桌面，旧回调不再重开菜单。此策略不表示所有新版系统都绝对禁止旧接口；其他安全类型也可能需要系统配置。Marco TV 不自行保存 Wi-Fi 密码，配置交给系统。换网络后 ADB 地址可能改变。

## 10｜开机、Home 和 ADB

这些是可选管理功能，先读[安装说明](安装说明.md)。

| 设置 | 用途 | 前提与边界 |
| --- | --- | --- |
| ADB 自动恢复 | 尝试恢复被关闭的调试开关 | 电脑授权；不保证恢复网络端口 |
| 状态中心 | 只读取权限、Home、ADB 和任务服务状态 | 不执行恢复，不代表实测通过 |
| 设为默认桌面 | 开放 HOME 候选并请求系统选择 | 是否采用由固件决定 |
| 开机打开 Marco TV | 收到开机广播后尝试进入 | 受自启动和后台限制影响 |
| Home 键兼容模式 | 直接响应 Home，必要时窗口兜底 | 需授权和本应用无障碍服务；可能仍闪过原桌面 |
| 立即执行已启用的恢复 | 确认后执行当前已启用的恢复配置 | 可能恢复调试开关或自身 Home 服务，不新增授权 |
| 唤醒后恢复桌面 | 待机唤醒后尝试恢复被系统结束的桌面 | 还需 Home 兼容与已连接的任务辅助服务 |
| 恢复原桌面 | 关闭默认入口、开机和兼容，恢复此前暂停的辅助服务 | 不会重装已卸载软件，ADB 自动恢复需另关 |

首次安装默认不启用这些管理功能，覆盖升级保留选择。权限仍有效时无需因升级反复授权。

## 11｜升级、备份与卸载

从官方 Releases 下载同一作者签名的新 APK，直接覆盖，或 `adb install -r`。先卸载会删除收藏、排序、导入图片等。升级前可从「备份与恢复」导出设置与图片，另存至电视之外。系统权限和默认桌面授权不能随配置迁移。

自行构建或其他来源若签名不同，不能直接覆盖；见常见问题。

卸载前：设置 →「系统与启动」→「恢复原桌面」，再关闭「ADB 自动恢复」。确认实体 Home 能回原桌面后，通过系统应用管理卸载。不再需要调试时，在系统关闭 ADB 并撤销电脑授权。

## 13｜添加、排序与播放卡片

### 手动添加应用

TV 应用选中第一张卡片后再按一次左键，在展开的分类操作栏中选择「添加应用」。应用行只显示真实应用。打开应用库后，先显示常用应用，顶部可以按名称或包名搜索；系统组件通过高级列表查找。选中应用后可直接使用默认入口添加，没有默认入口时可选择允许外部打开的公开页面。添加会将它放进 TV 应用并恢复隐藏状态；其他应用行不会再重复显示同一应用。默认未识别为电视应用的软件也可以加入。

系统服务可能没有可打开页面，软件会提示原因，不创建无效入口。不绕过系统对非公开页面、权限或已停用应用的限制。TV 应用暂时为空时，也可按左键展开操作栏添加。

### 单独卡片设置与排序

长按一张真实应用卡片 →「单独卡片设置」，可置顶 / 取消置顶、收藏 / 取消收藏、隐藏和卸载。置顶以小星标显示，在所属分类内优先。添加入口位于左侧操作栏，不参与卡片排序。隐藏也会隐藏收藏中的同一应用，可从设置恢复或重新添加。

普通应用卸载需经过应用内说明及电视系统确认；系统预装应用提供隐藏与系统应用信息入口。没有实际确认卸载前不会删除应用。

「应用与分类 → TV 应用排序」可切换：

| 方式 | 行为 |
| --- | --- |
| 上次打开（默认） | 最近从 Marco TV 打开的应用靠前；没有记录的按名称排列。记录只保存在电视本地，不监控其他应用的使用历史。 |
| 首字母排序 | 中文按拼音、其他名称按字母比较；重命名后的卡片名称参与排序。 |
| 纯自定义 | 使用长按菜单的向左 / 向右移动。移动 TV 应用时自动选择此模式，顺序跨重启保存。 |

三种模式都优先显示置顶应用，不能把非置顶卡片移到置顶卡片之前。自定义顺序单独保存，切换排序方式不会清空；其他分类仍使用各自的手动顺序。

### Wi-Fi 与图标背景

附近 Wi-Fi 列表每行只显示名称与弧线信号图标，安全类型在连接时处理，不再追加「几格」。同名但安全类型不同的热点仍是独立连接项，选择时确认详情。列表不会主动切换网络。

原始小图标会保留比例，并将自适应背景或图标边缘的主要背景色延伸至整个卡片。原始横幅和用户自定义封面保持现有显示方式；复杂背景图标可能仍有边界，可手动换封面。

### 正在播放卡片

「设备设置 → 正在播放卡片 → 打开通知使用权设置」，允许「Marco TV 正在播放」。此授权用于系统媒体会话，不读取或保存普通通知内容。电视不提供授权页面时，见安装说明的 ADB 方式。

媒体应用提供状态时，左上角显示封面、标题、来源和正在播放 / 已暂停。桌面按上键进入播放卡片，确定打开控制菜单，可返回播放应用，或在应用支持时暂停 / 继续。再按上键到设置 / Wi-Fi，向下返回应用行。触摸也可打开卡片。

没有会话、停止或释放会话时不显示；已暂停的会话仍可显示，正在播放的会话优先。某些视频应用按 Home 就停止并移除媒体会话，或从未向系统提供媒体信息，这种情况不会伪造「正在播放」卡片。不联网抓取封面或播放历史。可随时关闭卡片及撤销通知使用权。

## 14｜本地备份与恢复

设置首页 →「维护与帮助 → 备份与恢复」。本版不使用账号、云盘或作者服务器。

- **自动快照**：每次启动应用后，首次从桌面打开设置前自动保存一次完整配置，最近 3 份循环保留。不是每次调滑块都复制图片。
- **仅设置**：包含外观、收藏、置顶、隐藏、手动入口、排序和最近从桌面打开的时间；不含图片。恢复后自定义图片封面回到原始封面，壁纸使用内置选项。
- **设置与图片**：额外打包内部保存的自定义壁纸、卡片封面。原应用安装包、视频内容、账号和 Wi-Fi 密码不在备份中。
- **本地快照**：查看、恢复、导出或删除；手动快照不自动替你删除，定期移出重要备份并清理不需要的文件。

导出优先打开系统保存页面，可选择电视提供的存储位置或 U 盘。缺少系统文件选择器时，保存到 `Android/data/com.pilipala.tvhome/files/exports`，界面给出完整路径；请用文件管理器或电脑将文件复制到电视之外。这个备用目录仍会随卸载删除，不能当作永久外部备份。新版系统限制访问该目录时，需要安装提供系统文件选择器的文件管理器再导出。

恢复：选「从文件恢复」→ 选择 ZIP → 查看来源版本、图片数和缺失应用数 → 确认恢复。内部自动快照也可以直接恢复。系统缺少选择器时提供共享存储 ZIP 浏览器；Android 13 及以上需支持系统文件选择的文件管理器。

恢复前验证格式、参数范围、文件路径、图片和校验值，拒绝损坏或不支持的文件；当前版本限制展开后总量 128 MB、单张图片 32 MB。确认后自动生成 `before-restore.zip` 保存原配置。恢复中途失败会尝试回退；中断时下次打开会尝试从恢复前快照回退。

未安装应用不会代为安装，也不会显示失效卡片；其配置保留，便于之后安装。恢复不会导入 ADB、默认桌面、原系统屏保、通知使用权或无障碍授权，也不改变本地诊断开关。备份含应用名称、包名、启动时间与自选图片，是私人配置文件，不应直接附到公开反馈中。

## 15｜首次引导与状态检查

全新安装首次打开时显示 5 步引导，可逐步设置，也可随时跳过。覆盖升级保留设置，不强制重新引导。从「维护与帮助 → 首次使用引导」可以重新查看。

状态中心先显示简短概览；「查看详细状态」显示当前默认桌面、系统设置授权、Home 服务连接、开机开关、ADB 开关与恢复服务、最近检查记录、播放授权和可用会话。开关开启不等于所有场景都验证通过；网络端口、实体 Home、待机与重启需要实际检查。点击「重新检查」只读刷新，不自动修改系统配置。

## 16｜应用移动与播放来源

长按卡片 →「移动卡片」→ 左右移动 → 确定保存。返回取消并恢复原位置；Home 也会取消未确认移动。置顶组与普通组不能直接互相越过。保存 TV 应用移动后切换为纯自定义排序。

隐藏卡片后可以立即撤销。手动添加后关闭菜单并定位到新卡片。

播放卡片确定 →「选择播放来源」，可手动指定会话或恢复自动选择。自动模式优先正在播放；选择来源只改变桌面展示，不会停止其他播放器。「暂时隐藏此卡片」不暂停播放，可在「正在播放 → 恢复暂时隐藏的播放卡片」恢复。临时隐藏与来源选择只保留在本次应用进程，不写入播放历史。

缺少封面时使用播放器图标。暂停会话从本进程首次观察开始计时，30 分钟后收起；需要时可手动选回。停止或释放的会话不展示，不将仍存在的暂停会话称为播放中。

## 17｜本地诊断与反馈

设置首页 →「维护与帮助 → 本地诊断」，提供状态检查、报告预览、导出、自动记录开关和清除。

自动记录默认开启，最多保留 7 天、5 MB，仅在本机保存；同类连续事件限频。记录 Marco TV 自身异常类型、代码位置、关键操作结果、前台疑似无响应和上次运行中断线索。异常消息原文、媒体标题、视频地址、Wi-Fi 名称、IP、设备序列号、密码、普通通知与完整应用列表不加入报告。

报告包含品牌型号、系统 / 软件版本、当前配置状态和近期事件。先预览再导出，保存方式与备份相同。不会自动上传给作者或自动创建 GitHub 问题。可以把预览过的诊断文件附到反馈中，但不必公开备份文件。

关闭记录保留已有日志，清除可单独删除内部记录；已导出的文件需在保存位置另删。诊断不会自动删除应用、修改权限、重置网络或重启电视。

突然断电、系统强行结束进程可能没有完整错误信息；「上次运行中断，原因未确定」不能证明崩溃，「疑似无响应」也不是系统确认的 ANR。诊断不读取其他软件的完整系统日志，不保证捕获所有故障。

## 18｜系统最近任务与双击 Home

先按安装说明从电脑启动任务辅助服务，再到「最近任务」开启双击。单击 Home 立即回桌面，双击打开堆叠卡片；同一应用有多个系统任务时分别显示，不按应用包名合并。它读取系统任务，不采集进程列表或拼凑应用启动历史。

打开页面时，卡片从底部聚拢的位置上移并向两侧展开，背景同步压暗。左右选择，确定返回该任务原页面，上滑所选卡片或按遥控器上键清除任务，返回键关闭任务界面。菜单键进入「最近任务」，在「任务卡片与动画」调整卡片大小、间距、倾斜、圆角、背景暗度、展开与切换动画时长、显示数量；双击间隔位于上一层，共 8 项，可连续调节并实时预览。动画时长范围 120–700 毫秒，默认 280 毫秒；另有“试播切换”按钮。

上滑超过阈值或遥控器上键会直接清除当前任务，未保存的页面可能丢失。当前 Android 9 电视通过独立标准全屏窗口栈兼容实现清除；只有窗口栈仅含目标任务时才执行，共享窗口栈和系统桌面不执行。系统拒绝时保留卡片并提示。卡片使用不透明背景，优先系统缩略图，未提供时显示应用 Logo 与名称，不伪造屏幕截图。任务已结束、应用被卸载或接口不支持时，提示刷新。

「最近任务 → 状态中心」显示连接、版本、任务移除能力和最近一次唤醒检查结果。「系统与启动 → 唤醒后恢复桌面」配合 Home 兼容使用，恢复被系统结束的桌面进程，不抢占已在前台的其他应用。完整重启、断电及 APK 更新后，需要电脑重新启动辅助服务；普通待机无需重新启动。

备份保存这 8 项外观和交互参数，不迁移辅助服务、系统授权、双击启用或唤醒恢复开关。

## 19｜软件更新

入口：「维护与帮助 → 软件更新」。支持立即检查、下载、安装、更新内容、更新方式、稳定／体验渠道和取消下载。页面显示下载进度。

默认仅自动检查并提醒；选择“自动下载后提醒”后会使用当前网络下载，同样需要确认安装。检查仅在桌面前台调度，至少间隔 6 小时；不唤醒关闭的电视，不在其他应用中弹窗。首次进入或返回桌面会尝试调度，离线或服务不可达时继续使用当前版本。下载不支持断点续传，中断后可重试。

下载后核对文件完整性、包名、实际版本、系统要求和本机应用签名。安装前保存本地配置快照，再打开系统安装器。首次可能需要在系统中允许 Marco TV 安装未知应用；允许后返回更新页重新选择安装。厂商不开放安装器时仍可用 U 盘或电脑覆盖安装。更新不会自动授予权限、修改默认桌面或清除收藏／壁纸；安装时桌面会暂时退出。

默认只接收稳定版。体验渠道可能包含 RC 版本，切回稳定渠道不会降级。0.11.1 没有在线更新功能，须先手动覆盖安装一次带更新功能的版本。自行构建与官方包签名不同，不能通过本功能覆盖安装官方版本。

**最近任务辅助服务需单独检查。** APK 更新后到状态中心检查任务服务；当前实现仍需电脑重新启动辅助服务，不宣称自动恢复或静默更新。完整重启后也同样需要重新启动。
