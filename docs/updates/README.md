# Marco TV 更新源

作者：Pilipala · 2026-10-27

- stable.json：当前稳定发布，客户端默认使用。
- preview.json：体验渠道可用的公开版本；没有更新的体验版时可与稳定版一致，让体验版用户升级到正式版。

客户端至少间隔 6 小时检查，显示及安装以实际 APK 的版本、签名、系统要求与摘要校验为准。索引不上传任何设备数据，不提供远程执行指令。

发布顺序：构建与测试 → 发布 GitHub 安装包 → 验证资产 SHA-256 → 使用 scripts/make_update_feed.py 从该 APK 生成索引 → 发布 GitHub Pages → 从真实客户端验证。

不要为了让老版本检测到更新而伪造 versionCode。版本码必须与 APK 一致且递增。0.11.1 没有在线更新模块，必须先手动覆盖安装带更新功能的版本。索引仅引用已经发布的包；源代码包中保留的索引是打包时快照，在线索引可后续独立更新。

镜像发布与故障回退见[镜像更新部署](../镜像更新部署.md)。
