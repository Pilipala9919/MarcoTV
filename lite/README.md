**本软件免费开源。如果你付费购买了本软件，请尽快向购买平台申请退款。**

面向 Android 4.0 起步的轻量桌面，独立于完整版安装和维护。本版继续使用真正的 Android API 14 桩库编译（Dalvik `dex 035`），无联网权限、无后台服务，同步下放亮壁纸全界面自适应对比度、时间颜色模式与对比阴影、免联网本机天气探测显示、`card_surface` 卡片高光、圆角磨砂行标题角标、首张卡片左按快捷导航栏、多壁纸图库、手动非桌面 Activity 入口及 API 21+ 反射电视输入源独立行（Magic Desktop 扩展至 29 项可调参数）。**尚无 Android 4.x / 5.1 老电视与小米盒子 3c 真机实测验证，暂作为实验版招募反馈。**

## 0.4.0 更新

- **亮壁纸全界面自适应与时间配色自定义**：接入共享 `DesktopContrast`，自动采样壁纸左上、右上及卡片行区域亮度并结合壁纸压暗联动深色墨字与浅色亮字，同步适配顶栏图标/文字/焦点胶囊、时间日期天气、行标题、磨砂角标与卡片名称对比；Magic Desktop 新增「时间字体颜色」（10 种模式含 HSL 自定义）、「自定义色相」、「自定义明度」与「文字对比阴影」，屏保压暗自动提亮深色墨字。
- **免联网本机系统天气探测与日期下方显示**：接入 `LocalWeatherProbe`、`WeatherSnapshot` 与 `WeatherIcons`（零联网权限、零周期重绘），支持在日期下方渲染天气图标（矢量彩色/单色）、实时温度、温度范围与降雨概率，并新增「桌面天气探测」面板查看本机接口可读/权限受限诊断结果。
- **下放完整版高兼容视觉与交互**：新增 `card_surface` 卡片光学高光质感、行标题左侧圆角磨砂角标、首张卡片再按左键展开快捷导航栏、本地多壁纸图库（「我的壁纸库」支持多张本地导入与删除）、非桌面 Activity 入口手动添加器，以及 Android 5.0+（API 21+）反射识别电视硬件输入源独立行。

## 0.3.1 更新（历史记录）

- **修复系统选择器「仅此次」误报为默认桌面**：`LiteActivity` 改以系统当前实际 `HOME + DEFAULT` 解析结果判定默认桌面状态，明确区分「已设为默认」「仅本次临时打开」「由其他桌面接管」「尚未设为默认」与无 HOME 声明的受限版普通启动；保持纯 API 14、零联网权限、零后台服务与零辅助服务边界不变，并新增真实类运行时回归检查。

## 0.3.0 更新（历史记录）

- **统一官方品牌图标与视觉语言**：同步启用 MarcoTV 官方 **紫调三层叠卡** 4 套多密度 PNG 图标（完整保留 Android 4.0–15 与小米盒子 3c 安装兼容）、首页顶栏 `MARCO TV` 动态三层叠卡品牌徽标与薰衣草紫焦点/滑块点缀，并在卡片纯色封面首位新增「丁香紫」。

  - **收藏分组与双行切换**：单应用菜单新增「加入收藏 / 取消收藏」；收藏后首页按 `↓` / `↑` 在「我的应用」与「收藏」两行间平滑切换并独立保存顺序。
  - **「拿起并移动」拖拽排序**：单应用菜单选择「拿起并移动」后卡片浮动抬起，方向键左右即时换位，确定保存，返回取消。

  - 清单仅新增非特权、非联网的普通权限 `android.permission.REQUEST_DELETE_PACKAGES`（Android 4.0–8.1 自动忽略，Android 9+ `targetSdk=28` 调起系统卸载弹窗所必需），仍保持零联网权限、零存储权限、零后台服务。
- **同步完整版兼容特性（纯 API 14 原生实现）**：
  - **顶栏精简与三图标弹簧动效**：移除首页左上角冗余副标题，顶栏重绘为 `MARCO TV`、`Magic Desktop`、`全部应用` 3 枚纯 Canvas 矢量图标并接入 `MotionSpring` 焦点动画（关闭「卡片动效」时自动静止零重绘）。
  - **卡片视觉与尺寸自定义**：主行标题统一更名为「我的应用」并扩大卡片行向下移动范围；卡片升级平滑三段光学玻璃渐变、柔和双层悬浮阴影与亮白焦点描边；Magic Desktop 新增全局 **「卡片宽度」**（`70–140%`）、**「卡片立体厚度」**（`0–100%`）与 **「闲置纯净壁纸」**（复用共享 `ClockScene`）；长按任意卡片支持独立 **「自定义卡片尺寸」**（宽 / 高 / 立体厚度 / 圆角 + 实时桌面预览）。
  - **本地壁纸与默认桌面入口**：设置菜单新增免存储权限的 **「导入本地壁纸」**（通过 `ACTION_GET_CONTENT` 选取图片并安全降采样至 720p `RGB_565` 缓存至应用内部）以及 **「设为默认桌面」** 快捷入口。
- **针对小米盒子 3c（Android 5.1）等老设备的安装兼容修复**：
  - 将旧版无固有尺寸的 XML 图标（`res/drawable/app_icon.xml`）替换为 4 套标准多密度 PNG 图标（`mdpi / hdpi / xhdpi / xxhdpi`），补全 `android.software.leanback` 非必需声明与 `@string/app_name`，并规范 `build_lite.py` 的 ZIP 头提取版本与 `D8 --release` 字节码打包。
  - 新增可选的无 `HOME` 声明受限兼容包 `MarcoTV-Lite-0.2.0-Restricted.apk`，供固件拦截第三方桌面安装的设备（如部分小米盒子 3c / TCL 系统）尝试。

## 安装与首次试用（含小米盒子 3c 提示「检测安装包异常」排查）

1. 在电视/盒子「关于／系统信息」核对实际 Android 版本。不是 Android 或不能安装 APK 的系统，不适用此版本。
2. 下载 **`MarcoTV-Lite-0.4.0.apk`**（若固件限制第三方桌面 `HOME` 声明，可尝试无 `HOME` 声明的 **`MarcoTV-Lite-0.4.0-Restricted.apk`**）。普通完整版 APK 不能用于 Android 4.x / 5.x。
3. 在电视中允许未知来源安装，通过 U 盘、浏览器、厂商文件接收或电脑 ADB 安装。
4. **若小米盒子 3c（Android 5.1）或小米电视在 U 盘安装时提示「检测安装包异常，无法安装」**：
   - 请务必使用 `0.2.0` / `0.4.0` 及以上版本（已修复旧版 XML 图标为标准多密度 PNG 并规范 ZIP 打包）；
   - 如仍被小米自带「高清播放器 / 应用安装器」拦截，通常是 MIUI TV 联网安全校验或第三方桌面拦截导致：请先开启「允许安装未知来源应用」，再**断开电视/盒子网络（关闭 Wi-Fi 或拔掉网线）后通过 U 盘安装**；
   - 或开启「允许 ADB 调试」后用电脑/手机通过 `adb install -r MarcoTV-Lite-0.4.0.apk` 安装；也可以试用无 `HOME` 声明的 `MarcoTV-Lite-0.4.0-Restricted.apk`。
5. 从原厂应用列表打开 **Marco TV Lite**，先检查卡片、应用启动、方向键、长按管理和返回键。
6. 如系统允许选择默认桌面，可在「设置 → 设为默认桌面」或系统设置中选择 Lite。恢复时从系统设置改回原厂默认桌面，或卸载 Lite。

开发者可用 `adb -s <设备序列号> install --no-streaming -r MarcoTV-Lite-0.4.0.apk` 安装。

## 遥控器与设置

- 左右选择卡片，确定打开应用；向右超过第二张后平滑滚动。
- 上键进入顶部 **「MARCO TV（设置）」「Magic Desktop」「全部应用」**，下键回卡片行。
- 长按确定打开单应用管理菜单：置顶到首位 / 取消置顶、隐藏 / 取消隐藏、卸载应用（系统确认）、重命名、向左 / 向右移动、自定义卡片尺寸、系统应用信息、打开应用。
- 进入「全部应用」可集中查看所有已识别与已隐藏应用，左右键快速翻页，按确定进入单应用管理或卸载。
- Magic Desktop 中上下选择，左右调整参数；滚动到底部选择「保存」「取消」「恢复默认值」。参数预览不立即写入设置，返回或 Home 丢弃草稿。单张卡片「自定义卡片尺寸」左右调整即时预览生效，并可一键恢复跟随全局默认。
